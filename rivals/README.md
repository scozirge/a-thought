# 紅藍槍戰｜網頁版

**[點這裡開啟網頁版，直接開始遊玩](https://scozirge.github.io/a-thought/rivals/)**

在大廳選擇「手機觸控」或「鍵盤滑鼠」，建立房間或加入朋友的小隊。兩種操作方式都能使用右上角的全螢幕按鈕；手機建議橫向遊玩。

遊戲採 4 對 4，空位由電腦玩家補齊。隊伍先達 30 擊殺獲勝，死亡 3 秒後在隨機位置復活。

首次載入需要下載遊戲資源，請等進度完成。完整操作與自行架站方式見 [使用說明](使用說明.txt)。

手機瞄準改為點一下開啟、再點一下關閉，可邊瞄準邊射擊與轉向；手機不再顯示中央操作提示。所有版本已移除滑行。

本次連線版本為 `rivals-web-17-touch-controls`；同玩者請重新整理網頁，Windows 玩家請下載新版。
