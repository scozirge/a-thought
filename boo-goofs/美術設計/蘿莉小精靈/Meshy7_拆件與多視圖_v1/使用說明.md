## 完整角色：一次生成一隻穿好衣服的角色
進入 Image to 3D，Model Type 選 High Detail，AI Model 選 Meshy 7，開啟 Multi-View。
- 主圖：01_完整角色四視圖/01_Front.png
- Left：01_完整角色四視圖/02_Left.png（鼻尖朝畫面左）
- Back：01_完整角色四視圖/03_Back.png
- Right：01_完整角色四視圖/04_Right.png（鼻尖朝畫面右）
側面命名依上傳角度槽與圖像朝向標記；如介面方向示意不同，依介面示意對應。
四張均為同一套服裝與 A-pose；側面投影時手臂與雙腿有重疊屬正常。
Multi-View 目前需 Pro 或以上方案，最多主圖加 3 張。不可同時開啟 Smart Topology。
生成 → 檢查造型 → Remesh／Retopology → 貼圖檢查 → Rig → 測試動作 → 匯出帶骨架的 FBX／GLB。
這組會生成完整穿著模型，不保證自動得到可換裝、獨立配件或完整衣服下身體。

## 拆件：每張各自生成一個資產
不要把七種不同部件一起塞入一次 Multi-View；它只用來描述同一物件的不同角度。
七張目前各為單張獨立物件設計圖，不是每件四視圖。
- 01_角色基底：無頭髮與配件、穿不透膚灰色連身衣的比例基底。用於臉型、比例、綁定起始參考；不是完整裸身拓樸，灰衣也可能被生成為幾何，製作換裝身體時仍需整理。
- 02_狗耳朵：兩隻垂耳與髮箍構成一個配件。
- 03_眼鏡：完整鏡框與展開的鏡腳。鏡片在生成圖中偏乳白，3D 結果若封成實心，請分離／刪除鏡片後另設透明材質，或只保留鏡框。
- 04_耳飾：單隻耳飾放大圖，生成後複製成一對。微小金屬接點是根據原稿補全的製作解讀。
- 05_頭髮：獨立長髮外殼概念。內部與背面仍須檢查，單張不能保證內側形狀。
- 06_衣服：白襯衫＋金色格紋背心合為上身服裝一件；不是襯衫與背心分成兩個檔案。
- 07_裙子：獨立深咖啡色長裙與荷葉邊。

## 遊戲組裝建議
以下為製作建議，不是 Meshy 上傳硬性規格。
1. 定好身體比例及實際身高，再統一所有部件比例與原點。各部件圖是放大展示，不能依圖片像素推算實際尺寸。
2. 狗耳、眼鏡可掛到 Head 骨；耳飾可掛頭部或另外做擺動骨。
3. 頭髮、上衣、裙子需要合適權重；長裙避免直接照雙腿蒙皮而在跨步時撕扯，可加裙骨或限制動作幅度。
4. 可換裝模型要有衣服下方需要露出的完整身體表面，並處理被遮住的幾何與穿模。
5. 關節與手指變形、法線、UV、材質數、LOD、三角面數應在引擎內驗證。
6. 小配件與臉部特徵不要只靠全身圖重建；拆件圖可用於獨立製作。
7. 原稿頸飾上的 DOG 小字未被精確保留，這版是簡化紫色吊牌；如需原字樣，後续以貼圖補回。
