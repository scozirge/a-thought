## 大藝術家

角色保留酒紅舞台服、暗金邊飾、舊舞台鞋與迎接觀眾的姿態。真容改為非寫實的惡靈造型，以失衡的五官比例、巨大不對稱眼眶、扭曲嘴形、凌亂稀疏頭髮及乾裂舞台妝表現。身體採僵硬歪斜的謝幕姿勢，主圖直接顯示真容，旁邊保留背面與面部特寫。

前三張面具沿用第一版的辨識元素。壓抑面具改為向前突出的長方體鐵囚籠，包含欄杆、頂底板、鎖頭，以及縮在籠內、抓住欄杆的陶瓷臉與手部雕刻。籠內人臉與手是面具整體的固定造型。後續建模應沿用共同佩戴支架，並為囚籠前伸的深度預留空間。

壓抑的效果仍依文字稿為「動作變慢」，不改成完全不能操作。

### 角色圖的生成限制

含上吊死法與寫實屍體細節的首次角色生成，被影像工具安全系統拒絕。實際交付改用非寫實惡靈變形與舞台妝容呈現恐怖感，圖中未直接描繪自傷行為或寫實死後痕跡；使用者的文字身世仍依設計稿保留。

## 戲院的兩層模組

### 第一層：零件組成房間

以下是便於開始製作的原型建議尺度，需依角色、視角、搬運與救援操作在引擎內調整；不是已驗證尺寸。

| 類別 | 建議 |
| --- | --- |
| 拼接格線 | 2 公尺 |
| 地板／天花板 | 2 × 2 公尺單元 |
| 直牆 | 寬 2 公尺、高 3 公尺；牆厚一致 |
| 門牆 | 使用相同牆單元與固定接點，門洞由統一門框處理 |
| 基本房間 | 6 × 6 公尺外殼；房門使用預設接點 |
| 走廊 | 直線、轉角、T 字及交叉接點；可用地板格擴寬 |
| 最終演出室 | 可先用四個基本房間面積合併，約 12 × 12 公尺 |
| 四面具牆 | 兩片標準直牆形成約 4 公尺寬背景，保留四個獨立掛點 |

建築色彩沿用米色上牆、灰綠下牆、紅色木門、磨石子地板及暖黃燈。牆面污漬與海報以少量共用材質或貼花變化處理。布幕、門框與舞台邊緣保持簡單形狀。

共用家具以椅子、桌子、鐵櫃、木箱、化妝鏡、衣架、海報框與壁燈為主，必要變體可共用同一模型與材質。

| 房間用途 | 主要重複零件與家具 |
| --- | --- |
| 化妝間 | 基本外殼＋化妝鏡、桌、椅 |
| 服裝間 | 基本外殼＋衣架、鐵櫃 |
| 道具庫 | 基本外殼＋木箱、鐵櫃 |
| 排練室 | 基本外殼＋鏡面、少量椅子，保留空地 |
| 辦公室 | 基本外殼＋桌、椅、鐵櫃 |
| 休息室 | 基本外殼＋桌椅、海報框 |

房間圖省略面向觀看者的牆以便檢視；實際房間需補齊對應標準牆或門牆。

### 第二層：房間組成地圖

- 使用同一外殼的多個房間，透過門位變體、旋轉與陳設差異重複出現。
- 直走廊、轉角與 T 字岔路把房間群串起來；多次轉彎使玩家難以一眼看穿整區。
- 在房間群之間安排回到舊路的迴圈，以及少量有搜索價值的末端房間。
- 重複的門、牆與家具製造相似感；少數海報、燈色或陳設地標提供隊友報位與玩家學習路線的線索。
- 家具不要堵住門洞，轉角與門口要留出多人移動、追逐及救援需要的空間。
- 首版可採單層，先驗證同層房間重複拼接的效果。
- 正式拼裝時需檢查全部必要房間可達、門洞正確對接，四張面具能經由實際路線帶到目標牆。

### 四面具牆與最終演出室

最終演出室由普通房間模組擴大而成，保留低木舞台、簡單布幕與兩側入口。四面具牆是獨立專用模組，具有恰好四個掛位，設置高度應依小朋友角色的互動範圍調整。

掛位使用共用背面支架，前方保留囚籠面具的體積；牆面掛板外形不應成為只能容納平面面具的硬性凹槽。四個掛位與背牆以外的舞台結構，優先使用共用零件。
