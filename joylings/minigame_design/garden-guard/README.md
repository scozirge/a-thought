# 小小守園隊

給小學生試玩的策略塔防網頁原型。純 HTML、CSS、JavaScript、SVG 角色及 WebP 花園插畫，沒有外部執行依賴。

```powershell
npm start
npm test
npm run build
```

預設網址 `http://127.0.0.1:18130/`，也可直接開啟 `index.html`。建置輸出 `dist/h5/` 和單檔 `dist/garden-guard.html`；單檔可雙擊遊玩、複製到其他電腦，不需要伺服器。

## 十關連續防守

十關共用一張 12×8 草地戰場，左邊是小屋，前七關怪物從最右欄出現，第 8～10 關增加靠右側的上、下入口。每關是一波連續隊列，每實際 0.25 秒出一隻，不等待上一種蟲清空。入口從 3 個逐步增加為 5、6、10、12 個；新增入口會顯示相應方向的箭頭，該格不能蓋建築。前關留在新入口的建築會全額退款，其他建築保留。

- 第 1 關以 48 枚金幣及 5 顆心開始，可以不限時部署；比原本 60 少 20%。第十關正常累積預算由 270 降至 226。
- 按「開始」才進入第 1 關。戰鬥中不能建造、拆除或撤回；暫停也不解鎖部署。
- 當關隊列、怪物與飛行中的子彈都清空後，發放固定獎金，自動進入下一關的部署階段。普通擊殺、產卵及分裂不額外產錢。
- 進入下一關部署時，小屋恢復到 5 顆心。保留存活的砲塔、小石牆、建築耐久與剩餘金錢；被拆毀的建築不恢復。
- 部署時可新增建築，也可按橡皮擦圖示，再點某座塔或牆，退回完整原價；可撤回這次操作。
- 按「下一關」才出下一波。部署沒有倒數，也不會自動開始。
- 清空部署圖示會移除目前建築並全額退款；戰鬥中同一圖示改為重試當關，恢復開戰前的配置、金錢、生命和隨機種子。
- 中途失敗可重試當關，前關成果保留。只有第 10 關完成才顯示全程通關視窗；重玩會回到第 1 關。

## 暫時的測試選關與解答

左上角下拉選單可直接選第 1～10 關，切換時重設為空白盤面、5 顆心，並提供從第 1 關正常累積且沒有建築損失時的總預算。這是使用者要求暫時保留的測試入口；正常過關不走這個重設流程。選單的輔助名稱與提示註明切換會重設盤面。

「解答」會清空目前戰鬥與部署，將當前關卡恢復為正常總預算、5 顆心，再照正常價格扣款放上解答；剩餘金錢保留，停在部署階段，按開始才出怪。戰鬥中或暫停時也可使用，效果相當於重設當關；可繼續拆塔退款、修改解答。配置放在 `solutions.js`，遊戲按鈕及通關測試共用同一份資料。

各關使用固定隨機種子，讓直接選關和正常推進有相同的初始隨機序列；同一關重試也可重現分裂落點。建造順序、攻擊時機及怪物死亡位置仍會影響後續戰況。

## 操作與尋路

選工具，再點草地放置。指向工具列或已建造砲塔顯示資訊；手機點選或鍵盤聚焦也可查看，Escape 關閉。工具列只顯示圖示與費用，不增加常駐說明或路線開關。

小蟲身上的數字是剩餘生命；一般砲塔和穿透每次減 1、大砲減 2、分子砲減 28。直接傷害與燃燒都使用整數，血量不出現小數。盾的方向固定相對畫面，上盾抵擋從上方的攻擊、下盾抵擋下方攻擊，同高側面有效。厚金屬甲殼有不同顏色、分面和鉚釘；格擋時整片盾面、包邊和鉚釘會一起閃白，並在外緣產生火花與彈開效果，不減血、不觸發塔的附加效果。

小石牆花費 1、耐久 4；塔的耐久是 5，也會擋路。有任何通路時必須繞開建築；完全封路才沿忽略可破壞建築後的最短路徑前進，遇到建築每約 0.43 秒拆 1 下。打開通路後重新尋路。使用四方向、等步長 BFS，不走斜線；左右邊界保留為出入口。

引擎每秒 60 個固定模擬步進，戰鬥時鐘為 1.5 倍速；下列秒數均為實際遊玩時間。小蟲約每秒 1.23 格、盾蟲 1.02 格、長腳蟲 2.48 格。

## 七種砲塔

| 砲塔 | 金幣 | 傷害 | 攻擊次/s | 射程 | 目標 | 效果 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 一般砲塔 | 4 | 1 | 1.8 | 3.1 | 地/空 | 單體傷害 |
| 大砲範圍塔 | 12 | 2 | 1.2 | 2.8 | 地 | 半徑 1.25 格的範圍傷害 |
| 冰凍塔 | 8 | 1 | 0.9 | 2.65 | 地/空 | 命中處半徑 1 格緩速，移速降至 48%，維持 1.4 秒 |
| 火焰塔 | 8 | 1＋燃燒 1/s | 0.6 | 2.8 | 地 | 地板燃燒 3 秒 |
| 直線穿透塔 | 12 | 1 | 0.8 | 6.2 | 地/空 | 沿直線貫穿，每隻只命中一次 |
| 擊退塔 | 16 | 1／每隻 | 0.35 | 4 | 地/空 | 最近優先，同格目標沿可行路線退最多 3 格 |
| 分子砲 | 32 | 28 | 0.4 | 6.6 | 地/空 | 高血量優先，瞄準 2.5 秒後射擊 |

資訊卡五行依序為名稱、傷害、攻擊次數、目標、效果，與戰鬥共用數據。大砲與火焰不選空中目標，範圍傷害也不波及飛蟲或跳躍中的跳蟲；子彈飛行途中起跳也會重新檢查。

冰凍塔仍對主目標造成 1 傷害，命中後以落點為中心，緩速半徑 1 格內的地面與空中目標。周圍目標只緩速，不額外扣血或觸發首次受傷跳躍；重複命中會刷新緩速時間。主目標被擊殺仍會擴散，但被盾甲擋下就不擴散，周圍盾蟲也各自依攻擊來源判斷格擋。以冰圈與雪花顯示範圍。

穿透塔射程保持 6.2 格，傷害回到 1，攻速降為每秒 0.8 次（每 1.25 秒一發）；選敵範圍、射程圈與子彈最遠飛行距離共用設定。分子砲射程 6.6 格、每發 28 傷害，第八關 56 血巨蟲兩發擊殺；第九、十關強化巨蟲為 64、76 血，仍需三發。開始瞄準時選射程內「目前剩餘血量」最高的存活怪物，包含飛蟲；同血量先選靠近家的怪物，再以出生先後排序。紫色瞄準線持續追蹤同一目標，準星圓環顯示 2.5 秒的瞄準進度；之後才發射子彈。目標死亡或離開射程就取消進度，換目標並重新瞄準，不因新高血量敵人進場而中斷既有鎖定。上一發命中或消失後，才依當下剩餘血量重新選擇最高者，避免以扣血前的血量又鎖定同一隻。每發皆需重新瞄準 2.5 秒，另有約 0.13 秒子彈飛行時間；暫停會凍結瞄準，重試清空進度。除擊退塔最近優先外，其餘塔維持靠近家優先，盾甲方向仍影響命中。

火焰一擊擊殺仍留火；目標先被其他塔擊殺時，火焰彈飛到最後位置點燃地板。火區半徑 0.75 格，維持 3 秒、每秒扣 1；同格只延長時間，重疊火區不疊傷，離開就不受傷。地面火由下方接觸，上盾受傷、下盾格擋、空中不受傷。最後的火焰保留在部署／通關畫面，下次開戰時清除。

擊退塔射程 4 格，優先選離塔最近的敵人，每次只攻擊命中時該敵人所在的一格。以當前位置四捨五入判斷格子，同格且仍在射程內的地空目標各受 1 傷害，沿最多 3 格的可行路線，選擇「走回家距離」最遠的落點；相鄰格不受影響。地面敵人以 BFS 到家的距離判斷遠近，遇牆或邊界會轉彎尋路，動畫跟隨完整折線，不穿建築。完全包圍且沒有更遠的安全位置時才留在原地。飛蟲忽略建築，以到家的直線距離選擇落點；動畫後重新尋路。攻速由 0.5 降低 30% 至 0.35 次/s，約每 2.86 秒攻擊一次。盾蟲保留格擋規則，跳蟲首次受傷優先跳躍，跳躍途中不被拉回障礙物。原選定目標先消失就攻擊最後瞄準的位置，同次死亡分裂的新生小蟲不會被追溯攻擊。特效只標出受影響的一格，搭配實際退向的箭頭。

穿透彈遇盾格擋後停止。暫停凍結所有怪物、子彈、產卵、跳躍、擊退與燃燒。

### 簡單平衡計算

直接傷害 DPS＝每發傷害×每秒攻擊次數；每 10 枚金幣輸出＝DPS÷價格×10。這是持續命中、無格擋、無溢出傷害時的基準，不計走出射程、轉火與子彈時間。

| 砲塔 | 單一目標直接 DPS | 每 10 枚金幣的直接 DPS | 判讀 |
| --- | ---: | ---: | --- |
| 一般砲塔 | 1.80 | 4.50 | 價格 4，攻速從 1.5 提高 20% 至 1.8 次/s，適合單體補漏與低血量對空，射程較短 |
| 大砲範圍塔 | 2.40 | 2.00 | 由 9 調至 12，同時打 3 隻合計 7.20 DPS，只能打地面 |
| 冰凍塔 | 0.90 | 1.13 | 直接傷害只算主目標，1 格內群體緩速；持續減速時經過同樣距離的時間約為原本 2.08 倍 |
| 火焰塔 | 0.60 | 0.75 | 由 10 降至 8，補償地面限定與燃燒延遲；地火另外每隻 1/s，持續命中單體約 1.60 DPS，重疊火區不疊傷 |
| 直線穿透塔 | 0.80 | 0.67 | 由 10 調至 12，同線 3 隻合計 2.40 DPS；長射程與排成直線才有優勢 |
| 擊退塔 | 0.35／每隻 | 0.22／每隻 | 由 9 調至 16，定價包含 4 格射程與反覆後退的控制能力；只顧最近一格可能漏掉其他路線 |
| 分子砲 | 11.20 | 3.50 | 由 14 調至 32，瞄準 2.5 秒造成 28 傷害；單體效率接近一般塔，高血量、遠距離最適合，打小蟲會溢傷 |

穿透的總輸出取決於排成直線的命中數；大砲取決於爆炸範圍內的地面蟲數；火焰取決於留在火區的時間，不能把它的每秒燃燒重複疊算。控制塔的低直接 DPS 不能單獨代表弱勢。數值調整後也驗證合法通關測試配置，關卡總出怪數維持原設定，預算已下調。

`npm run balance` 以固定出怪比較地面蟲群、空中蟲群、上盾蟲群、56 血巨蟲與混合蟲群。每塔分別單獨測量，以及搭配兩座一般塔測量額外有效傷害；只計實際扣除的血量，不把溢傷算進去。穿透使用有利的直線佈位，其餘塔在路旁，結果寫入 `dist/balance-report.json`。此為特定路線的比較，不能解讀為所有地圖的勝率；控制效果另看支援增益，超過 200 實際秒的樣本會標為未結束。

## 保存與介面

讀取部署存檔或重試時，小屋恢復到 5 顆心；舊存檔同樣適用。已完成第十關的存檔保留當時剩餘生命，供通關畫面顯示。

`localStorage` 使用獨立鍵 `garden-guard-v1`，存檔版本為 9。部署存檔保存目前關卡和配置；戰鬥中重新整理恢復當關開戰前的盤面，過關後保存下一關部署，第十關完成的狀態也會保存，不重複發獎金。舊版先依其原有經濟換算，再扣除新舊累積預算差額一次；已購建築及其退款價格保留，現金最低為零。再次讀檔或重試不重複扣款。舊版放在新增入口的建築會全額退款。舊子波次歸零，想用新版標準預算測試可直接選關或按「解答」。

第 8 版開始，每座建築保存原購買價 `paidCost`，拆除退回實際支付的完整金額，撤回及重試也保留該價格。讀入第 7 版以前的塔按調價前價格處理：例如舊分子砲退 14、舊火焰塔退 10，新買分子砲退 32、新火焰塔退 8。調整售價不會額外向舊盤面收費，也不會因讀檔把退款改成新售價。

畫面保留選關、紅愛心、金幣、棋盤、工具與操作按鈕。過關加錢時短暫顯示 `+獎金`，不加說明卡。一般文字至少 18px，按鈕至少 48px，小蟲數字為 28px SVG 文字。戰場最窄 736px，手機橫向滑動戰場；工具列四欄兩列並固定在下方。

支援方向鍵移動格子、Enter／空白鍵放置、Tab 聚焦、Escape 取消。切換分頁自動暫停。沒有連線、登入、成績後台或強制雙人輪流；教育內容融入數字減法、預算、方向、地空分類與最短路徑。

### 花園美術

七種砲塔、小石牆、九種蟲和彈體共用 `art.js` 的向量圖。工具列、放置預覽和戰場使用同一套塔圖。每隻蟲的體型由出生時的生命值決定，初始生命越高，體型就稍大，大小約介於四分之三格到一格之間。受傷時體型固定，血量數字會更新。分裂蟲背上的三瓣斑點甲殼在分裂時各自散向一隻小蟲。血量數字固定字級，蟲群靠近時會在蟲身上下錯開。花園背景為 `garden.webp`，建置時會隨樣式嵌入網頁和離線單檔。

七種砲塔各有不同的彈體與尾跡。大砲沿弧線拋射，火焰彈落地後留下有邊界的燃燒區，穿透箭沿直線飛行，分子砲發射帶粒子環的光彈。血量數字位於特效上方；暫停時彈道與火苗也會停住。

## 驗證

`npm test` 包含戰鬥機制、尋路、盾甲、地空判定、十關累積預算通關、無牆及單一塔種對照、獎金一次性、部署凍結、保留建築、每關生命補滿、單塔退款、重試、舊存檔和全程完成存檔。`tests/layouts.cjs` 直接引用 `solutions.js`，驗證按鈕所使用的十關解答。

瀏覽器測試直接開啟本地單檔，也可用 `GARDEN_URL` 指定伺服器。使用隔離進度，不更動使用者存檔。

```powershell
npm run build
$env:PLAYWRIGHT_PATH = '既有 Playwright 套件的絕對路徑'
npm run test:browser
```

Windows 預設使用已安裝的 Edge，可用 `CHROME_PATH` 覆寫。測試涵蓋前兩關正常推進、最後一關實戰及結算保存、退款重佈、選關、暫停、九種蟲能力、七種塔資訊、鍵盤、觸控、1440／900／390／320px 與 200% 縮放。畫面輸出到忽略的 `dist/browser-check/`。`npm run test:auto-waves` 可單獨執行關卡流程驗證。

`npm run test:controls` 驗證冰凍群體緩速但周圍不扣血、單格擊退沿路遠離家、分子砲瞄準線跟隨與暫停、2.5 秒後射擊及整數傷害資訊。邏輯測試另檢查範圍邊界、盾甲、原目標消失、死亡分裂、障礙物、穿透慢攻速、56 血巨蟲兩發擊殺，以及新舊售價退款。

`npm run test:solutions` 驗證十關解答都能通關、價格不超過預算、按鈕清空舊盤面、戰鬥與暫停重設、儲存恢復、入口箭頭與 1440／390／320px 按鈕可用性。

公開遊戲：https://scozirge.github.io/a-thought/garden-guard/

原始碼位於 `scozirge/a-thought` 的 `master`。使用者要求發布時，先通過測試、提交並推送本次變更，再建置並把 `dist/h5/` 六個檔案同步至既有 `gh-pages` checkout 的 `garden-guard/`。提交訊息使用繁體中文，保留根目錄 `.nojekyll` 與其他遊戲。
