# 小小守園隊

給小學生試玩的策略塔防網頁初版。純 HTML、CSS、JavaScript、自製 SVG，沒有外部執行依賴；可直接開啟 `index.html`，或啟動本機伺服器。

```powershell
npm start
npm test
npm run build
```

預設網址：`http://127.0.0.1:18130/`。可用 `node serve.cjs 其他埠號` 更改。靜態輸出在 `dist/h5/`，也可直接開啟其中的 `index.html`。建置同時產出 `dist/garden-guard.html` 單檔版本，雙擊即可遊玩，也能複製到其他電腦。

## 操作與規則

- 選工具，再點草地放置。滑鼠指向格子可看射程；介面不顯示預計路線或路線開關。
- 小蟲固定從右側入口出現，前往左側小屋。家有 5 顆心，每隻進家扣 1。
- 每隻小蟲身上的數字就是剩餘有效命中次數。三種塔每次有效命中都只扣 1。
- 第一個花園的第一波直接出現 5 隻、每隻 3 下的盾蟲。盾蟲以暖色身體、深色金屬厚甲區分，上方甲殼有分面、厚邊與鉚釘。擋住來自畫面上方的攻擊；下方與同高側面攻擊有效。盾方向固定，不隨移動轉彎改變。上方子彈在甲殼外緣產生火花、閃光並彈開，不扣數字，也不觸發減速。介面只用蟲圖片呈現，不另外放名稱或解說卡。
- 戰鬥整體為原版的 1.5 倍速：怪物移動、出怪、射擊、子彈、減速與拆牆同步加快，維持原有策略比例。以下秒數以實際遊玩時間計。
- 第一隻約 0.33 秒出現，後續每隻間隔約 0.97 秒。小圓蟲每秒約 1.23 格、盾蟲 1.02 格、快腳蟲 1.70 格。
- 豆豆塔：6 種子，射程 3.1 格，間隔 0.70 秒。連發塔：9 種子，射程 2.2 格，間隔 0.32 秒。冰花塔：8 種子，射程 2.65 格，間隔 1.10 秒，命中使移速降至 48%，維持 1.40 秒。
- 小石牆：1 種子、4 下耐久。工具列只顯示圖示與費用，保留輔助閱讀名稱。塔也佔格、擋路，可被拆除，耐久為 5。
- 有任何通路時，小蟲會繞開建築。只有完全封路，才會沿忽略可破壞建築後的最短路線前進，遇到建築停下，每約 0.43 秒拆 1 下。打開通路後重新尋路。
- 棋盤採四方向、等步長 BFS 最短路徑，不走斜線。石頭與池塘不可破壞；左右邊界保留為出入口。
- 準備階段沒有倒數，玩家按播放圖示放蟲。戰鬥固定使用較快節奏，可按暫停圖示觀察；建造與移除留到兩波之間。
- 準備時可全額移除、退一步。擊退一隻得 1 種子，過一波再得 4 種子，建築於波次結束修好。
- 失敗可重試該波，恢復開始前的建築、資源與生命，不必從第一波重來。

## 內容與教育設計

三張地圖各四波：青草地學方向與射程，小池塘學引導路線，兩條路學分配有限資源。一般蟲、盾蟲與快腳蟲讓數量、速度、射程和方向形成取捨。

教育內容放在操作結果：數字逐一下降、比較攻擊方向、比較繞路前後的攻擊時間、規劃種子預算。沒有另外加入考卷、長篇教學或強制輪流。兩個孩子可一人觀察數字與路徑、一人操作；不宣稱存在強制雙人模式。

`tests/layouts.cjs` 保存三張地圖的可通關測試配置，不顯示在遊戲中。池塘測試同時驗證：相同火力拿掉引導牆會失敗，確保路線策略不是裝飾。

## 介面與保存

主畫面只保留花園數字、生命與種子數字、棋盤、工具圖示與費用，以及撤回、移走、重來、開始／暫停圖示。移除標題、花園名稱、側欄、波次預告、工具名稱、常駐提示、版本號、倍速、路線與路線開關。放置無效時以格子外框短暫變色回饋；工具名稱及錯誤訊息仍可由輔助工具讀取。

一般遊戲文字至少 18px；小蟲數字以 28px SVG 文字呈現，戰場最窄顯示寬度為 736px，維持實際字級與點選範圍。窄螢幕可橫向滑動戰場，整組工具與開始／暫停固定在下方；桌機建議完整顯示。

鍵盤可用 Tab 進入棋盤，再以方向鍵移動焦點，Enter／空白鍵放置，Escape 取消工具。切到其他分頁會自動暫停。

獨立 `localStorage` 鍵為 `garden-guard-v1`，保存目前波次的準備盤面。重新整理戰鬥會回到該波開始前。切換花園或按重來會重設該花園。儲存失敗不影響遊玩，無效存檔回到初始狀態。驗證使用隔離瀏覽器，不碰使用者進度。

## 驗證

`npm test` 執行 Node 內建測試：最短路徑、繞路、完全堵路拆牆、地形、盾甲方向、命中計數、減速、預算、撤回、存檔、暫停、失敗重試，以及全部 12 波的合法滿生命解法。

瀏覽器測試需要外部 Playwright，可指定 `PLAYWRIGHT_PATH`，以及選用的 `CHROME_PATH`。Windows 預設嘗試已安裝的 Microsoft Edge。

```powershell
$env:PLAYWRIGHT_PATH = '既有 Playwright 套件的絕對路徑'
npm run test:browser
```

測試包含滑鼠、鍵盤、觸控、儲存、拆牆、全新開局第一波的硬甲與上方格擋不扣血、下方扣血、勝負、重試、四種視窗寬度與 200% 縮放；畫面輸出在不納入提交的 `dist/browser-check/`。

## H5 發布

公開遊戲：https://scozirge.github.io/a-thought/garden-guard/

原始碼提交至 `scozirge/a-thought` 的 `master`。通過測試後執行 `npm run build`，將 `dist/h5/` 的五個檔案同步至既有發布 checkout 的 `garden-guard/`，以繁體中文提交並推送至 `gh-pages`。建置自動在 CSS 與 JavaScript 引用加上內容雜湊版本，避免載入前一版快取。保留根目錄 `.nojekyll` 與其他遊戲；待 Pages 建置完成後驗證五個公開檔案及全新開局的建造、盾甲、上方格擋與下方扣血。

發布完成後執行 `npm run test:published`（同樣需要 `PLAYWRIGHT_PATH`），自動比對本機建置與公開檔案，並實際操作第一波驗證盾蟲。報告保存在 `dist/published-report.json`。

這是單人網頁原型，沒有連線、登入、課堂成績後台或 Roblox Studio 專案。
