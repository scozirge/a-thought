# 小小守園隊

給小學生試玩的策略塔防網頁原型。純 HTML、CSS、JavaScript、SVG 角色及 WebP 花園插畫，沒有外部執行依賴。

```powershell
npm start
npm test
npm run build
```

預設網址 `http://127.0.0.1:18130/`，也可直接開啟 `index.html`。建置輸出 `dist/h5/` 和單檔 `dist/garden-guard.html`；單檔可雙擊遊玩、複製到其他電腦，不需要伺服器。

## 十關連續防守

十關共用一張 12×8 草地戰場，左邊是城堡。當蟲進入 3 格射程，城堡會朝靠近的地面或空中目標射箭，每秒 1.55 箭，每箭造成 2 點單體傷害。第一關從右邊三個入口輪流出蟲，每 0.50 秒一隻，上盾蟲先到，小蟲跟在後面。之後逐步增加入口，第 8～10 關加入上、下入口，第 9、10 關再把怪物編成小隊交錯進場。每關的怪物連續出現。新入口會標示方向，原先蓋在該格的建築會依購買價退款。

- 第一關有 48 枚金幣、5 顆心和不限時的部署時間。一路過關時，第十關共可支配 226 枚金幣。
- 按「開始」才進入第 1 關。戰鬥中不能建造、拆除或撤回；暫停也不解鎖部署。
- 部署時，綠色箭頭顯示地面蟲的路線；封死通路會改用褐色提示拆牆路線，有飛蟲的入口另畫藍色虛線。
- 滑鼠移到場上的塔或牆可查看上局實際扣掉的血量，包含範圍傷害、彈射、地火與餘燼。
- 當關隊列、怪物與飛行中的子彈都清空後，顯示勝利、固定獎金及 1 顆升級晶石，自動進入下一關的部署階段。普通擊殺、產卵及分裂不額外產錢。
- 進入下一關部署時，城堡恢復到 5 顆心。保留存活的砲塔、小石牆、建築耐久與剩餘金錢；被拆毀的建築不恢復。
- 部署時可新增建築，也可按橡皮擦圖示，再點某座塔或牆，退回完整原價；可撤回這次操作。
- 按「下一關」才出下一波。部署沒有倒數，也不會自動開始。
- 清空部署圖示會移除目前建築並全額退款；戰鬥中同一圖示改為重試當關，恢復開戰前的配置、金錢、生命和隨機種子。
- 中途失敗可重試當關，前關成果保留。守住第 10 關後顯示主線通關視窗，可選擇挑戰隱藏第 11 關。

### 隱藏第 11 關「四面守園」

守住第十關後，按「挑戰第 11 關」進入獨立戰場。中央城堡位在第 6 欄、第 4 排，有 5 顆心及 250 枚起始金幣。四個入口各在城堡的正上、正下、正左、正右，每 0.42 秒輪流出一隻蟲，三段攻勢之間沒有部署時間。

| 攻勢 | 預排數 | 考驗 |
| --- | ---: | --- |
| 第一段 | 41 | 長腳蟲與飛蟲搶先進場，母蟲沿地面路線產卵 |
| 第二段 | 50 | 巨蟲吸引重砲火力，同時要接住飛蟲、分裂蟲與跳蟲 |
| 第三段 | 52 | 快蟲混在盾蟲與巨蟲之間，母蟲和小蟲從後方補入 |

通關資格保存在同一瀏覽器。讀入已完成第十關的舊存檔也能開啟。解鎖後在選關選單可重玩；教師的 `?tip=true` 在解鎖後可套用本關的正常預算解答。

示範部署花 250 枚金幣，以兩圈錯開的牆口引導地面蟲，讓塔能同時防守直飛中央的飛蟲。四路地面蟲分別要走 36、19、27、10 格。實測剩 4 顆心，拿掉石牆或將雷射砲換成石牆都會失守。

執行 `npm run balance:bonus` 可用固定種子再測隨機部署、雙塔組合與微調陣形的通關情形。

## 選關與教師解答

左上角下拉選單可直接選第 1～10 關，切換時重設為空白盤面、5 顆心，並提供從第 1 關正常累積的總預算。這是使用者要求暫時保留的測試入口；正常過關不走這個重設流程。選單的輔助名稱與提示註明切換會重設盤面。

一般網址只提供玩家操作。網址查詢參數包含 `tip=true` 時才會出現「解答」按鈕。按下後會清空目前戰鬥與部署，將當前關卡恢復為正常總預算與起始生命，再照正常價格扣款放上解答；剩餘金錢保留，停在部署階段，按開始才出怪。戰鬥中或暫停時也可使用，效果相當於重設當關；可繼續拆塔退款、修改解答。配置放在 `solutions.js`，遊戲按鈕及通關測試共用同一份資料。

第 9 關的雷射砲架在下方折返處，能在蟲群折返時沿直線命中多隻。用石牆取代這座雷射而保留相同路線，這套陣形會失守。

各關使用固定隨機種子，讓直接選關和正常推進有相同的初始隨機序列；同一關重試也可重現分裂落點。建造順序、攻擊時機及怪物死亡位置仍會影響後續戰況。

## 操作與尋路

選工具，再點草地放置。指向工具列或已建造砲塔顯示資訊；手機點選或鍵盤聚焦也可查看，Escape 關閉。工具列只顯示圖示與費用，路線可在「顯示設定」開關。

第一關預設在蟲身旁標出剩餘生命，第 2～10 關預設隱藏。展開戰場下方靠右的「顯示設定」，可勾選或取消「顯示本關怪物血量」。重試或重新整理會保留本關的選擇，進入另一關時採用該關預設。

一般砲塔和雷射砲每次減 1、大砲減 2、分子砲減 28。直接傷害與燃燒都使用整數，血量不出現小數。蟲頭、蟲腳和翅膀會跟著移動方向轉動，血量數字保持正立。盾的方向固定相對畫面，上盾抵擋從上方的攻擊、下盾抵擋下方攻擊，同高側面有效。雷射砲和分子砲從任何方向都能穿過盾牌，命中時直接扣血。厚金屬甲殼有不同顏色、分面和鉚釘；格擋時整片盾面、包邊和鉚釘會一起閃白，並在外緣產生火花與彈開效果，不減血、不觸發塔的附加效果。

小石牆花費 1、耐久 4；塔的耐久是 5，也會擋路。有任何通路時必須繞開建築；完全封路才沿忽略可破壞建築後的最短路徑前進，遇到建築每約 0.43 秒拆 1 下。打開通路後重新尋路。使用四方向、等步長 BFS，不走斜線；左右邊界保留為出入口。

引擎每秒 60 個固定模擬步進，戰鬥時鐘為 1.5 倍速；下列秒數均為實際遊玩時間。小蟲約每秒 1.23 格、盾蟲 1.02 格、長腳蟲 2.48 格。

## 升級晶石

每通過一關獲得 1 顆晶石，可以留到後面使用。部署時按「升級」，再點有紫框的一座建築。每座花 1 顆，可升級一次，金幣與建築耐久保持原值。

| 建築升級 | 戰鬥效果 |
| --- | --- |
| 雙管連射塔 | 左右砲管交替開火，攻速為原本的 2.5 倍，每秒 3.875 發，每發 1 點傷害。 |
| 震盪拳塔 | 命中格內每隻蟲受 4 點傷害，最多擊退 4 格，停下後暈 1 秒。每少退一整格多暈 1 秒，完全推不動時暈 5 秒。 |
| 連鎖分子砲 | 每次瞄準 2 秒，電漿擊中後找 3 格內最近且尚未擊中的蟲。連續命中傷害為 28、9、3、1。 |
| 重裝大砲 | 大型砲彈在原有爆炸範圍內造成 4 點傷害。 |
| 霜晶冰凍塔 | 攻速提升 20%，每秒 1.08 次。每次靈氣命中同時造成 1 點傷害與緩速。 |
| 餘燼火焰塔 | 火球直擊造成 3 點傷害。火地維持 3 秒，每秒造成 1 點傷害。蟲離開後每秒再受 1 點傷害，持續 5 秒。 |
| 電弧雷射砲 | 命中直線上的地面與空中目標，各觸電停住 0.4 秒（普通為 0.1 秒，升級追加 0.3 秒），仍可穿盾。 |
| 尖刺石牆 | 一格內有蟲時伸刺，最多每秒一次，範圍內每隻受 1 點傷害並暈眩 0.1 秒。 |

| --- | ---: | ---: | ---: | ---: | --- | --- |
| 一般砲塔 | 5 | 1 | 1.55 | 3.1 | 地/空 | 單體傷害 |
| 大砲範圍塔 | 11 | 2 | 1.2 | 2.8 | 地 | 半徑 1.25 格的範圍傷害 |
| 冰凍塔 | 7 | 0 | 0.9 | 2.65 | 地 | 以塔為中心，半徑 2.65 格緩速，移速降至 70%，維持 1.4 秒 |
| 火焰塔 | 7 | 1＋燃燒 1/s | 0.6 | 3.2 | 地 | 地板燃燒 3 秒 |
| 雷射砲 | 15 | 1 | 0.8 | 6.2 | 地/空 | 沿直線穿過盾牌和蟲群，每隻只命中一次 |
| 擊退塔 | 9 | 1／每隻 | 0.35 | 4 | 地/空 | 靠近城堡優先，同格目標沿可行路線退最多 3 格 |
| 分子砲 | 18 | 28 | 0.5 | 6.6 | 地/空 | 高血量優先，瞄準 2 秒後射出可穿盾的電漿球 |

資訊卡五行依序為名稱、傷害、攻擊次數、目標、效果，與戰鬥共用數據。大砲與火焰不選空中目標，範圍傷害也不波及飛蟲或跳躍中的跳蟲；子彈飛行途中起跳也會重新檢查。

冰凍塔在敵人靠近時，從塔身放出一圈冰凍靈氣。半徑 2.65 格內的地面目標會緩速 1.4 秒，飛蟲和躍在空中的跳蟲不受靈氣影響，每隻盾蟲按自己面向塔的方向格擋。受緩速的蟲全身轉為冰藍並帶雪花。普通塔保留目標血量，升級塔每次命中扣 1 點。冰圈本身就是攻擊提示。

雷射砲每 1.25 秒發射一道最長 6.2 格的光束。發射瞬間沿直線依序命中地面與空中的蟲，每隻受 1 點傷害。光束從正面也能打傷盾蟲，再繼續命中同一直線上的蟲。分子砲射程 6.6 格、每發 28 傷害，第八、九、十關的巨蟲有 76、106、218 血，若完全由分子砲攻擊，分別需要三、四、八發。開始瞄準時選射程內「目前剩餘血量」最高的存活怪物，包含飛蟲；同血量先選靠近家的怪物，再以出生先後排序。紫色瞄準線持續追蹤同一目標，準星圓環顯示 2 秒的瞄準進度；之後向當時的落點發射大型電漿球。電漿球穿過上盾與下盾，未升級時每發只對一隻蟲造成傷害。目標死亡或離開射程就取消進度，換目標並重新瞄準，不因新高血量敵人進場而中斷既有鎖定。上一發命中或消失後，才依當下剩餘血量重新選擇最高者，避免以扣血前的血量又鎖定同一隻。每發皆需重新瞄準 2 秒，另有約 0.13 秒子彈飛行時間；暫停會凍結瞄準，重試清空進度。一般砲塔、大砲、冰凍塔、火焰塔與雷射砲優先瞄準靠近家的蟲，擊退塔優先瞄準離城堡最近的蟲。

火球在發射時定下落點，著地處的草地泛紅，冒出幾簇低矮的小火苗。蟲移開、起跳或先被擊殺時，火球仍在原落點點燃地板。火區半徑 0.75 格，維持 3 秒、每秒扣 1；同格只延長時間，重疊火區不疊傷，離開就不受傷。地面火由下方接觸，上盾受傷、下盾格擋、空中不受傷。最後的火焰保留在部署／通關畫面，下次開戰時清除。

擊退塔射程 4 格，優先選離城堡最近的敵人，每次朝發射時瞄準的那一格打出氣波。落點依發射時的位置四捨五入，同格且仍在射程內的地空目標各受 1 傷害，沿最多 3 格的可行路線，選擇「走回家距離」最遠的落點；相鄰格不受影響。地面敵人以 BFS 到家的距離判斷遠近，遇牆或邊界會轉彎尋路，動畫跟隨完整折線，不穿建築。完全包圍且沒有更遠的安全位置時才留在原地。飛蟲忽略建築，以到家的直線距離選擇落點；動畫後重新尋路。攻速由 0.5 降低 30% 至 0.35 次/s，約每 2.86 秒攻擊一次。盾蟲保留格擋規則，跳蟲首次受傷優先跳躍，跳躍途中不被拉回障礙物。原選定目標先消失，氣波仍抵達發射時瞄準的格子，同次死亡分裂的新生小蟲不會被追溯攻擊。拳套的氣波在命中時消散，蟲的後退動作顯示實際路線。

暫停時，怪物、彈體、雷射、冰凍靈氣與地面火焰都會停在當前畫面。

### 簡單平衡計算

直接傷害 DPS＝每發傷害×每秒攻擊次數；每 10 枚金幣輸出＝DPS÷價格×10。這是持續命中、無格擋、無溢出傷害時的基準，不計走出射程、轉火與子彈時間。

| 砲塔 | 單一目標直接 DPS | 每 10 枚金幣的直接 DPS | 判讀 |
| --- | ---: | ---: | --- |
| 一般砲塔 | 1.55 | 3.10 | 補漏與低血量對空，射程較短 |
| 大砲範圍塔 | 2.40 | 2.18 | 同時打 3 隻地面蟲合計 7.20 DPS |
| 冰凍塔 | 0 | 0 | 全範圍緩速，讓目標經過同樣距離的時間約為原本 1.43 倍 |
| 火焰塔 | 0.60 | 0.86 | 每隻地面蟲另受地火傷害 1/s，重疊火區只延長時間 |
| 雷射砲 | 0.80 | 0.53 | 同線 3 隻合計 2.40 DPS，可對空 |
| 擊退塔 | 0.35／每隻 | 0.39／每隻 | 同格擊退可讓一群蟲重新經過火區 |
| 分子砲 | 14.00 | 7.78 | 每發瞄準 2 秒，適合高血量目標，打小蟲容易溢傷 |

穿透的總輸出取決於排成直線的命中數；大砲取決於爆炸範圍內的地面蟲數；火焰取決於留在火區的時間，不能把它的每秒燃燒重複疊算。控制塔的低直接 DPS 不能單獨代表弱勢。各關以可用預算實測不同陣形。

`npm run balance` 以固定出怪比較地面蟲群、空中蟲群、上盾蟲群、56 血巨蟲與混合蟲群。每塔分別單獨測量，以及搭配兩座一般塔測量額外有效傷害；只計實際扣除的血量，不把溢傷算進去。穿透使用有利的直線佈位，其餘塔在路旁，結果寫入 `dist/balance-report.json`。此為特定路線的比較，不能解讀為所有地圖的勝率；控制效果另看支援增益，超過 200 實際秒的樣本會標為未結束。

`npm run balance:routes` 會輸出 `dist/route-balance.json`。第一關用一般塔分守三路、在屋前再留火力，120 組過 112 組；換成一般塔搭配一座大砲，120 組過 110 組。第 5～10 關各打 160 場，選塔有混合火力、重砲、集中普通塔和雷射等做法，每次放置都保留所有入口原本的最短距離。第 5 關有一組打贏，第 6～10 關全數失守。另一組保留教師陣形的所有砲塔和相同牆數、花費，把牆移到蟲路外，六關共 192 場全敗；原陣形六關都可通過。

## 保存與介面

讀取部署存檔或重試時，主線城堡恢復到 5 顆心，隱藏關也恢復到 5 顆心。舊存檔同樣適用。已完成第十關的存檔保留當時剩餘生命，供通關畫面顯示。

`localStorage` 使用獨立鍵 `garden-guard-v1`，存檔版本為 14。舊存檔載入時，依已通過的關數一次補發晶石。另以 `garden-guard-bonus-unlocked` 保留已開啟隱藏關的紀錄。部署存檔保存目前關卡和配置；戰鬥中重新整理恢復當關開戰前的盤面，過關後保存下一關部署與上局各塔的實際傷害，第十關完成的狀態也會保存，不重複發獎金。舊版先依其原有經濟換算，再扣除新舊累積預算差額一次；已購建築及其退款價格保留，現金最低為零。再次讀檔或重試不重複扣款。舊版放在新增入口的建築會全額退款。舊子波次歸零，想用新版標準預算測試可直接選關或按「解答」。

第 8 版開始，每座建築保存原購買價 `paidCost`，拆除退回實際支付的完整金額，撤回及重試也保留該價格。讀入第 7 版以前的塔按調價前價格處理：例如舊分子砲退 14、舊火焰塔退 10，第九版購買的分子砲退 32、火焰塔退 8，第 10～12 版新買的則分別退 22、7。第 13 版起分子砲售價為 18。舊隱藏關存檔移到新版地圖時，中央城堡和新入口占用的建築會退回造價與投入的晶石。調整售價不會額外向舊盤面收費，也不會因讀檔把退款改成新售價。

畫面保留選關、紅愛心、金幣、棋盤、工具與操作按鈕。過關加錢時短暫顯示 `+獎金`，不加說明卡。一般文字至少 18px，按鈕至少 48px，小蟲數字為 23px SVG 文字。戰場最窄 736px，手機橫向滑動戰場；工具列四欄兩列並固定在下方。

支援方向鍵移動格子、Enter／空白鍵放置、Tab 聚焦、Escape 取消。切換分頁自動暫停。沒有連線、登入、成績後台或強制雙人輪流；教育內容融入數字減法、預算、方向、地空分類與最短路徑。

### 花園美術

七種砲塔、小石牆、九種蟲和彈體共用 `art.js` 的向量圖。工具列、放置預覽和戰場使用同一套塔圖。每隻蟲的體型由出生時的生命值決定，初始生命越高，體型就稍大，大小約介於四分之三格到一格之間。受傷時體型固定，血量數字會更新。分裂蟲背上的三瓣斑點甲殼在分裂時各自散向一隻小蟲。血量數字固定字級，蟲群靠近時會在蟲身上下錯開。花園背景為 `garden.webp`，建置時會隨樣式嵌入網頁和離線單檔。

一般砲塔射出小圓彈，大砲沿弧線拋出較大的鐵球，火焰塔發射橙色火球，升級後火球直徑約為普通版的 1.8 倍，分子砲則有帶電弧的大電漿球。彈體在開火時固定落點，飛行中沒有尾跡或地面投影。冰凍塔向四周釋放靈氣，雷射砲以發光鏡頭射出一道紅色光束。冰圈從水晶下方擴開，拳套會伸出再回彈，分子砲口的電漿會隨瞄準進度聚集。雷射在實際命中的位置冒出火花。血量數字在特效上方，暫停會凍結戰場動畫。蟲攻入城堡時，城垛上方會浮出裂成兩半的紅心。過關時最後一次攻擊仍能播完，下一波等玩家按下按鈕才開始。

## 驗證

`npm test` 包含戰鬥機制、尋路、盾甲、地空判定、十關累積預算通關、無牆及單一塔種對照、獎金一次性、部署凍結、保留建築、每關生命補滿、單塔退款、重試、舊存檔和全程完成存檔。`tests/layouts.cjs` 直接引用 `solutions.js`，驗證按鈕所使用的主線及隱藏關解答。

瀏覽器測試直接開啟本地單檔，也可用 `GARDEN_URL` 指定伺服器。使用隔離進度，不更動使用者存檔。

```powershell
npm run build
$env:PLAYWRIGHT_PATH = '既有 Playwright 套件的絕對路徑'
npm run test:browser
```

Windows 預設使用已安裝的 Edge，可用 `CHROME_PATH` 覆寫。測試涵蓋前兩關正常推進、最後一關實戰及結算保存、退款重佈、選關、暫停、九種蟲能力、七種塔資訊、鍵盤、觸控、1440／900／390／320px 與 200% 縮放。畫面輸出到忽略的 `dist/browser-check/`。`npm run test:auto-waves` 可單獨執行關卡流程驗證。

`npm run test:controls` 驗證冰凍全體只緩速、藍色蟲身、雷射砲口對齊、單格擊退沿路遠離家、分子砲瞄準線跟隨與暫停、2 秒後射擊及整數傷害資訊。邏輯測試另檢查範圍邊界、盾甲、原目標消失、死亡分裂、障礙物、穿透慢攻速、分子砲對第八關巨蟲的逐發扣血，以及新舊售價退款。

`npm run test:solutions` 驗證一般網址、`tip=false`、`tip=1` 及 `tip=True` 都沒有解答按鈕，並在 `tip=true` 下驗證十關及解鎖後的隱藏關解答都能通關、價格不超過預算、按鈕清空舊盤面、戰鬥與暫停重設、儲存恢復、入口箭頭與 1440／390／320px 按鈕可用性。
