# 小小守園隊

給小學生試玩的策略塔防網頁初版。純 HTML、CSS、JavaScript、自製 SVG，沒有外部執行依賴；可直接開啟 `index.html`，或啟動本機伺服器。

```powershell
npm start
npm test
npm run build
```

預設網址：`http://127.0.0.1:18130/`。可用 `node serve.cjs 其他埠號` 更改。靜態輸出在 `dist/h5/`，也可直接開啟其中的 `index.html`。建置同時產出 `dist/garden-guard.html` 單檔版本，雙擊即可遊玩，也能複製到其他電腦。

## 操作與規則

- 選工具，再點草地放置。指向工具列或已建造的砲塔，顯示名稱、傷害、攻擊次數與一句效果。手機點工具或已建造砲塔可查看；鍵盤聚焦也可查看，Escape 關閉。指向格子仍可看射程，介面不顯示預計路線或路線開關。
- 小蟲固定從右側入口出現，前往左側小屋。家有 5 顆心，每隻進家扣 1。
- 小蟲身上的數字是剩餘生命，每次有效攻擊依砲塔傷害扣除；一般砲塔扣 1、大砲扣 2、分子砲扣 6。
- 第一個花園的第一波直接出現 5 隻、每隻 3 生命的上盾蟲。上下盾蟲的深色金屬厚甲位於相對應的一側，有分面、厚邊與鉚釘；盾方向固定，不隨轉彎改變。同高側面與無盾側攻擊有效。格擋在甲殼外緣產生火花、閃光並彈開，不扣數字，也不觸發減速、擊退、爆炸或點火。穿透彈被擋下會停止。介面只用蟲圖片呈現，不另外放名稱或解說卡。
- 戰鬥整體為原版的 1.5 倍速：怪物移動、出怪、射擊、子彈、減速與拆牆同步加快，維持原有策略比例。以下秒數以實際遊玩時間計。
- 第一隻約 0.33 秒出現，後續每隻間隔約 0.97 秒。小蟲每秒約 1.23 格、盾蟲 1.02 格、長腳蟲 2.48 格。
- 小石牆：1 種子、4 下耐久。工具列只顯示圖示與費用，保留輔助閱讀名稱。塔也佔格、擋路，可被拆除，耐久為 5。
- 有任何通路時，小蟲會繞開建築。只有完全封路，才會沿忽略可破壞建築後的最短路線前進，遇到建築停下，每約 0.43 秒拆 1 下。打開通路後重新尋路。
- 棋盤採四方向、等步長 BFS 最短路徑，不走斜線。石頭與池塘不可破壞；左右邊界保留為出入口。
- 準備階段沒有倒數，玩家按播放圖示放蟲。戰鬥固定使用較快節奏，可按暫停圖示觀察；建造與移除留到兩波之間。
- 準備時可全額移除、退一步。消滅一隻得 1 種子，過一波再得 4 種子，建築於波次結束修好。
- 失敗可重試該波，恢復開始前的建築、資源與生命，不必從第一波重來。

## 七種砲塔

攻速是實際每秒攻擊次數，資訊卡和戰鬥共用同一份數值；引擎維持每秒 60 個固定模擬步進，以 1.5 倍戰鬥時鐘執行。

| 砲塔 | 種子 | 傷害 | 攻擊次/s | 射程 | 效果 |
| --- | ---: | ---: | ---: | ---: | --- |
| 一般砲塔 | 6 | 1 | 1.5 | 3.1 | 單體傷害 |
| 大砲範圍塔 | 9 | 2 | 1.2 | 2.8 | 半徑 1.25 格的範圍傷害 |
| 冰凍塔 | 8 | 1 | 0.9 | 2.65 | 移速降至 48%，維持 1.4 秒 |
| 火焰塔 | 10 | 1＋燃燒 1/s | 0.6 | 2.8 | 地板燃燒 3 秒 |
| 直線穿透塔 | 10 | 1 | 1.5 | 4.2 | 沿發射時的直線貫穿，每隻只命中一次 |
| 擊退塔 | 9 | 1 | 0.5 | 3 | 沿攻擊方向擊退 3 格 |
| 分子砲 | 14 | 6 | 0.4 | 3.6 | 單體高傷害 |

火焰命中後將所在格子點燃，火區半徑 0.75 格，每實際一秒造成一次傷害；同格重複點火只延長時間，重疊火區不疊傷，離開火區不繼續扣血。地板火焰從下方接觸敵人，上盾蟲會受傷、下盾蟲會格擋；飛蟲與跳躍中的跳蟲不受地板火焰影響。波次結束會清除火區。

擊退以約 0.2 秒的短動畫沿攻擊方向推開三格，撞到牆、砲塔、固定地形或邊界會提早停止，不會穿牆。到達後重新尋路。暫停會一併停止擊退、火地板與穿透彈。

## 十種蟲

| 種類 | 基礎生命 | 能力與外觀 |
| --- | ---: | --- |
| 小蟲 | 1 | 小型棕色一般蟲；所有關卡及出生的小蟲皆為 1 血 |
| 上盾蟲 | 3 | 橘色身體，上方厚甲抵擋上方攻擊 |
| 下盾蟲 | 3 | 綠色身體，下方厚甲抵擋下方攻擊 |
| 跳蟲 | 3 | 大後腿；首次非致命受傷向左跳，優先尋找兩格前的安全落點 |
| 母蟲 | 10 | 粉紅大身體帶卵；慢速移動，每實際 3 秒生一隻小蟲 |
| 飛蟲 | 2 | 藍色身體與拍動翅膀；直接飛向小屋，無視建築和固定地形 |
| 分裂蟲 | 4 | 綠色三瓣身體；死亡爆開，在半徑一格內分裂成 3 隻小蟲 |
| 巨蟲 | 20 | 大型棕色厚背甲；移動緩慢、生命較多 |
| 爆炸蟲 | 4 | 紅色身體帶發亮引線；死亡炸毀所在格周圍一格的建築，包含斜角 |
| 長腳蟲 | 2 | 黃色身體、長腳；速度約為小蟲的兩倍 |

各波可提高特殊蟲的生命，數字始終顯示實際剩餘生命。跳蟲可跨越障礙，落點在向左一至兩格、上下兩格的搜尋區域內，優先可通行且到家路徑最短的位置；沒有安全落點則留在原處。跳躍約 0.4 秒，途中不會被擊退拉進牆內，落地後繼續尋路。

分裂及產卵避開地形與建築，落點使用可重現的隨機數；重試同一波會還原隨機種子。同一次範圍攻擊不會追溯傷害剛分裂的小蟲。爆炸範圍為死亡所在格的 3×3 格，直接移除塔與牆，重新計算後續路徑；不破壞固定地形。進家消失不觸發死亡能力。所有塔都可攻擊飛蟲，擊退飛蟲時也可跨越障礙。

## 內容與教育設計

三張地圖各四波，蟲種逐步增加：青草地有小蟲、上下盾蟲與長腳蟲，共 4 種；小池塘新增跳蟲、母蟲、飛蟲，共 7 種；兩條路再加入分裂蟲、巨蟲、爆炸蟲，共 10 種。每關前幾波逐步介紹新能力，後面混合種類，讓攻擊方向、路線、範圍傷害與高傷害形成取捨。

教育內容放在操作結果：生命減去傷害、比較攻擊方向與頻率、比較繞路前後的攻擊時間、規劃種子預算。沒有另外加入考卷、長篇教學或強制輪流。兩個孩子可一人觀察數字與路徑、一人操作；不宣稱存在強制雙人模式。

`tests/layouts.cjs` 保存三張地圖的可通關測試配置，不顯示在遊戲中。池塘測試同時驗證：相同火力有引導牆能滿生命通關，拿掉引導牆會漏怪，確保路線策略會影響結果。

## 介面與保存

主畫面只保留花園數字、生命與種子數字、棋盤、工具圖示與費用，以及撤回、移走、重來、開始／暫停圖示。移除標題、花園名稱、側欄、波次預告、工具名稱、常駐提示、版本號、倍速、路線與路線開關。放置無效時以格子外框短暫變色回饋；工具名稱及錯誤訊息仍可由輔助工具讀取。

砲塔資訊平常隱藏，只在滑鼠指向、鍵盤聚焦或手機點選時出現，最多四行；例如「大砲範圍塔／傷害 2／攻擊 1.2次/s／範圍傷害」。戰鬥中也可查看。工具列包含七種塔與小石牆，手機排成四欄兩列。

一般遊戲文字至少 18px；小蟲數字以 28px SVG 文字呈現，戰場最窄顯示寬度為 736px，維持實際字級與點選範圍。窄螢幕可橫向滑動戰場，整組工具與開始／暫停固定在下方；桌機建議完整顯示。

鍵盤可用 Tab 進入棋盤，再以方向鍵移動焦點，Enter／空白鍵放置，Escape 取消工具。切到其他分頁會自動暫停。

獨立 `localStorage` 鍵為 `garden-guard-v1`，保存目前波次的準備盤面。重新整理戰鬥會回到該波開始前。切換花園或按重來會重設該花園。儲存失敗不影響遊玩，無效存檔回到初始狀態。驗證使用隔離瀏覽器，不碰使用者進度。

存檔內容版本為 3，新增隨機種子，仍接受第 1、2 版資料。舊連發塔自動轉為同價位的大砲範圍塔，保留關卡、波次、種子及位置。

## 驗證

`npm test` 執行 Node 內建測試：最短路徑、繞路、完全堵路拆牆、地形、盾甲方向、傷害、減速、爆炸範圍、燃燒計時與不疊傷、直線穿透、擊退距離與障礙物、分子砲、預算、撤回、舊存檔遷移、暫停、失敗重試，以及全部 12 波的合法滿生命解法。

共 44 項測試，另涵蓋十種蟲的關卡漸進、上下格擋、跳躍落點、三秒產卵、飛行穿牆、分裂數量與隨機範圍、爆炸拆除、死亡觸發一次及重試重現。

瀏覽器測試需要外部 Playwright，可指定 `PLAYWRIGHT_PATH`，以及選用的 `CHROME_PATH`。Windows 預設嘗試已安裝的 Microsoft Edge。

```powershell
$env:PLAYWRIGHT_PATH = '既有 Playwright 套件的絕對路徑'
npm run test:browser
```

測試包含七種塔的懸浮資訊、已建造塔資訊、鍵盤與觸控查看、五種新增攻擊特效，以及儲存、拆牆、全新開局盾蟲格擋、勝負、重試、四種視窗寬度與 200% 縮放；畫面輸出在不納入提交的 `dist/browser-check/`。

怪物瀏覽器測試另外操作下盾格擋、跳躍、母蟲產卵、飛蟲跨障礙、分裂及爆炸拆塔，並輸出十種蟲的造型檢查圖；該圖只供測試，不會新增到遊戲介面。

## H5 發布

公開遊戲：https://scozirge.github.io/a-thought/garden-guard/

原始碼提交至 `scozirge/a-thought` 的 `master`。通過測試後執行 `npm run build`，將 `dist/h5/` 的五個檔案同步至既有發布 checkout 的 `garden-guard/`，以繁體中文提交並推送至 `gh-pages`。建置自動在 CSS 與 JavaScript 引用加上內容雜湊版本，避免載入前一版快取。保留根目錄 `.nojekyll` 與其他遊戲；待 Pages 建置完成後驗證五個公開檔案及全新開局的建造、盾甲、上方格擋與下方扣血。

發布完成後執行 `npm run test:published`（同樣需要 `PLAYWRIGHT_PATH`），自動比對本機建置與公開檔案，並實際操作第一波驗證盾蟲。報告保存在 `dist/published-report.json`。

這是單人網頁原型，沒有連線、登入、課堂成績後台或 Roblox Studio 專案。
