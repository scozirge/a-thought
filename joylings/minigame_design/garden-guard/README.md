# 小小守園隊

給小學生試玩的策略塔防網頁原型。純 HTML、CSS、JavaScript、SVG 角色及 WebP 花園插畫，沒有外部執行依賴。

```powershell
npm start
npm test
npm run build
```

預設網址 `http://127.0.0.1:18130/`，也可直接開啟 `index.html`。建置輸出 `dist/h5/` 和單檔 `dist/garden-guard.html`；單檔可雙擊遊玩、複製到其他電腦，不需要伺服器。

## 十關連續防守

部署時，點塔或石牆，選「移動」再點空地，就能免費搬到新位置。點原位可以取消，搬好後按「退一步」可以復原。

十關共用一張 12×8 草地戰場，左邊是城堡。當蟲進入 3 格射程，城堡會朝靠近的地面或空中目標射箭，每秒射擊 1.55 次，每箭造成 2 點單體傷害。部署時可花 1 顆水晶升級城堡，每次向同一目標齊射兩箭，最大生命與當前生命各增加 1 顆心。第一關從右邊三個入口輪流出蟲，每 0.50 秒一隻，上盾蟲先到，螞蟻跟在後面。之後逐步增加入口，第 8～10 關加入上、下入口，蟲群從各入口輪流進場。每關的怪物連續出現。新入口會標示方向，原先蓋在該格的建築會依購買價退款。

- 第一關有 48 枚金幣、5 顆心和不限時的部署時間。連續通關或直接選關，第九、十關和隱藏第十一關的部署總預算依序為 170、208、230 枚金幣。部署總預算包含已花在建築上的金幣。
- 按「開始」才進入第 1 關。戰鬥中不能建造、拆除或撤回；暫停也不解鎖部署。
- 部署時只顯示地面蟲的路線。綠色箭頭標出行進方向，封死通路時改用褐色箭頭標出拆牆路線。
- 滑鼠移到場上的塔或牆可查看上局實際扣掉的血量，包含範圍傷害、彈射、地火與餘燼。
- 當關出怪完畢、黃蛋都已孵化、蟲群全數清除後結算。仍在滾動的雪球會清除，其他已發射的攻擊照常收尾。勝利獲得固定獎金及 1 顆升級水晶，第 3、5、7、9 關另有 1 把融合槌。
- 進入下一關部署時，普通城堡恢復到 5 顆心，升級城堡恢復到 6 顆。保留存活的砲塔、石牆、建築耐久與剩餘金錢；被拆毀的建築不恢復。
- 點場上的塔或牆，在旁邊選「拆除」會退回實付金幣和道具。按「退一步」可還原。
- 結算時按「繼續」留在本關。按右下角「下一關 →」進入部署，再按「開始」才會出怪。
- 部署時按「重置」會清空建築並全額退款。開戰後同一按鈕會顯示「暫停」。暫停時可按右側「繼續」，或按「放棄」回到當關開戰前的配置、金錢與生命。
- 城堡失守時，「再試一次」會依扣血順序列出蟲的圖示和名稱。重試會回到當關部署，保留前關成果。守住第 10 關後顯示主線通關視窗，可選擇挑戰隱藏第 11 關。

### 隱藏第 11 關「四面守園」

守住第十關後，按「繼續」，再按「下一關 →」進入獨立戰場。中央城堡位在第 6 欄、第 4 排，有 5 顆心及 230 枚起始金幣，先前升級的城堡有 6 顆心。四個入口各在城堡的正上、正下、正左、正右，每 0.42 秒輪流出一隻蟲，三段攻勢之間沒有部署時間。三段的第二隻固定是右側的巨顎鍬形蟲王、左側的獨角仙王、上方的織網蜘蛛王。

| --- | ---: | --- |
| 第一段 | 42 | 母蟲帶頭產卵，鍬形蟲王緊接著出場 |
| 第二段 | 51 | 巨蟲吸引重砲火力，同時要接住飛蟲、蟑螂卵與跳蟲 |
| 第三段 | 53 | 金龜蟲和蜘蛛王帶頭，飛蟲與蜈蚣稍後進場 |

通關資格保存在同一瀏覽器。讀入已完成第十關的舊存檔也能開啟。解鎖後在選關選單可重玩；教師的 `?tip=true` 在解鎖後可套用本關的正常預算解答。

隱藏關示範部署花 217 枚金幣配置導引牆和中央火力，還有 13 枚可以調整。能對空的塔同時照顧不同入口孵出的飛蟲，城堡升級後可發射雙箭、守住六顆心。

執行 `npm run balance:bonus` 可用固定種子再測隨機部署、雙塔組合與微調陣形的通關情形。

## 選關與教師解答

左上角下拉選單可直接選第 1～10 關，切換時重設為空白盤面、5 顆心，並提供從第 1 關正常累積的金幣、水晶和融合槌總額。這是使用者要求暫時保留的測試入口；正常過關不走這個重設流程。選單的輔助名稱與提示註明切換會重設盤面。

一般網址只提供玩家操作。網址查詢參數包含 `tip=true` 時才會出現「解答」按鈕。按下後會清空目前戰鬥與部署，將當前關卡恢復為正常總預算與起始生命，再照正常價格扣款放上解答；剩餘金錢保留，停在部署階段，按開始才出怪。戰鬥中或暫停時也可使用，效果相當於重設當關；可繼續拆塔退款、修改解答。配置放在 `solutions.js`，遊戲按鈕及通關測試共用同一份資料。

第 9 關解答用 170 枚金幣和 8 顆水晶。下方折返處的雷射砲能沿直線命中多隻，火龍捲和砲塔一起清掉飛蟲。

小蟑螂彈出的落點使用各關固定的亂數序列。隱藏關重試或讀檔時，三個蟲王的入口都固定。蜘蛛王的封塔目標在開戰時重新抽選，教師解答也遵循相同規則。

## 操作與尋路

橙色箭頭指向蟲蟲進場的方向，戴皇冠的紅色箭頭是蟲王入口。滑鼠指向箭頭會預覽蟲種，點一下就能打開這個入口的圖鑑。每頁最多 3 種，圖片下方有一句特性。用左右箭頭翻頁，右上角的 × 可關閉。

關卡名稱、入口和城堡生命會留在過關時的狀態，按下「下一關 →」才會切換。「此關再玩一次」會回到剛才那關開戰前的配置與資源，獎勵隨該次勝利一起重算。隱藏關通關後可直接重玩。

選工具，再點草地放置。指向工具列或已建造砲塔顯示資訊；手機點選或鍵盤聚焦也可查看，Escape 關閉。工具列只顯示圖示與費用，路線可在「顯示設定」開關。

第一關預設在蟲身旁標出剩餘生命，第 2～10 關預設隱藏。展開戰場下方靠右的「顯示設定」，可勾選或取消「顯示本關怪物血量」。重試或重新整理會保留本關的選擇，進入另一關時採用該關預設。

砲塔優先打飛蟲。雷射砲、雷管砲、急凍光束槍、激光砲和反動砲都會優先找一條能貫穿較多蟲的直線，升級後也一樣。

砲塔和雷射砲每次減 1、大砲減 2、電漿塔減 38。直接傷害與燃燒都使用整數，血量不出現小數。蟲頭、蟲腳和翅膀會跟著移動方向轉動，血量數字保持正立。盾的方向固定相對畫面，上盾抵擋從上方的攻擊、下盾抵擋下方攻擊，同高側面有效。雷射砲和電漿塔從任何方向都能穿過盾牌，命中時直接扣血。厚金屬甲殼有不同顏色、分面和鉚釘；格擋時整片盾面、包邊和鉚釘會一起閃白，並在外緣產生火花與彈開效果，不減血、不觸發塔的附加效果。

石牆花費 1、耐久 4；塔的耐久是 5，也會擋路。有任何通路時必須繞開建築；完全封路才沿忽略可破壞建築後的最短路徑前進，遇到建築每約 0.43 秒拆 1 下。打開通路後重新尋路。使用四方向、等步長 BFS，不走斜線；左右邊界保留為出入口。

引擎每秒 60 個固定模擬步進，戰鬥時鐘為 1.5 倍速；下列秒數均為實際遊玩時間。螞蟻約每秒 1.23 格、盾蟲 1.02 格、蜈蚣 2.48 格。

## 融合槌與配方

通過第 3、5、7、9 關各獲得 1 把融合槌。第三關結算後按「下一關 →」會顯示第一次融合的圖解。點場上的普通塔，選單會用三個塔圖示呈現「原塔＋材料塔＝成品」，並列出成品名稱、對地或對空與材料金幣。點配方會花 1 把融合槌，在原格合成。水晶或槌子用完時，將滑鼠移到對應按鈕可查看原因。點選單外會先收起選單，再點棋盤才會部署。兩種材料交換順序也能得到同一種塔。

融合塔占一格。點融合塔並花 1 顆水晶即可升級，取消升級會退回水晶。升級名稱在原名後加 `+`。棋盤左下的金邊工藝槌代表融合，水晶代表升級；兩者可並列。已升級的普通塔拿去融合時，會立即退回 1 顆水晶。拆除或被蟲摧毀的融合塔會退回兩份實付金額與融合槌。石牆可獨立升級成尖刺石牆。

平常指向砲塔可查看名稱、傷害、攻速、射程、目標與效果。資訊卡用格數標示射程、爆炸半徑、擊退或連鎖距離。戰術砲臺分別顯示對空與對地射程。點建築後指向旁邊的「升級」，可預覽下一階改變的數值。大砲與火焰不選空中目標，範圍傷害也不波及飛蟲或跳躍中的跳蟲；子彈飛行途中起跳也會重新檢查。

冰凍層數由各塔共用。寒冰砲、急凍光束槍與滾動的雪球每次命中疊兩層，其餘冰凍攻擊疊一層。第 1～6 層分別緩速 10%、12%、14%、16%、18%、20%。再次命中會刷新 1.4 秒緩速，時間到時層數歸零。第 7 層凍住普通蟲 1.5 秒、蟲王 0.5 秒。七層結凍與凍結電漿共用保護時間。結凍時再次命中不會延長冰封，解凍後 1 秒內免疫冰凍緩速、疊層和直接冰封，攻擊仍可造成傷害。燃燒中再次點燃會立刻扣一血並刷新燃燒時間。

寒冰石在敵人靠近時，從塔身放出一圈冰凍靈氣。半徑 2.65 格內的地面目標會緩速 1.4 秒，飛蟲和躍在空中的跳蟲不受靈氣影響，靈氣會穿過上盾和下盾。蟲身和盾牌會隨層數從淺藍變為深藍，第 6 層達到最深的冰藍色。普通塔保留目標血量，升級塔每次命中扣 1 點。冰圈本身就是攻擊提示。

雷射砲每 1.25 秒發射一道最長 6.2 格的光束。發射瞬間沿直線依序命中地面與空中的蟲，每隻受 1 點傷害。光束從正面也能打傷盾蟲，再繼續命中同一直線上的蟲。電漿塔射程 6.6 格、每發 38 傷害，第八、九、十關的巨蟲有 76、106、218 血，若完全由電漿塔攻擊，分別需要二、三、六發。開始瞄準時選射程內「目前剩餘血量」最高的存活怪物，包含飛蟲；同血量先選靠近家的怪物，再以出生先後排序。紫色瞄準線持續追蹤同一目標，準星圓環顯示 1.5 秒的瞄準進度；之後向當時的落點發射大型電漿球。電漿球穿過上盾與下盾，未升級時每發只對一隻蟲造成傷害。目標死亡或離開射程就取消進度，換目標並重新瞄準，不因新高血量敵人進場而中斷既有鎖定。上一發命中或消失後，才依當下剩餘血量重新選擇最高者，避免以扣血前的血量又鎖定同一隻。每發皆需重新瞄準 1.5 秒，另有0.36 秒直飛時間，每次連鎖再飛 0.30 秒，抵達後才扣血；暫停會凍結瞄準，重試清空進度。砲塔、大砲、寒冰石、火焰塔與雷射砲優先瞄準靠近家的蟲，衝擊拳機優先瞄準離城堡最近的蟲。

燃燒中的蟲再次被點燃時，立即額外扣 1 血並重新計時。新的一次持續灼傷會在一秒後跳傷害，這筆額外傷害歸給再次點燃的塔。

普通和升級投石塔每秒攻擊 0.45 次。投石機會依地面蟲的行進路線，挑落地到地火熄滅前最多蟲會經過的格子。數量相同時，優先選火石落地時能打中較多蟲的位置。投石臂拋出燃燒石，約 0.5 秒後落在發射時鎖定的格子。著地時飛散火星與岩屑，同格所有地面蟲各自判定直擊和盾牌格擋。蟲離開時仍在原格點燃地板。火區半徑 0.75 格，普通版維持 4 秒，升級版維持 5 秒，每秒扣 1。重疊地火對同一隻蟲每秒只判定一次，已在燃燒的蟲同時觸發再次點燃。地面火由下方接觸，上盾受傷、下盾格擋、空中不受傷。最後的火焰保留在部署／通關畫面，下次開戰時清除。

衝擊拳機射程 4 格，優先選離城堡最近的敵人，每次朝發射時瞄準的那一格打出氣波。落點依發射時的位置四捨五入，同格且仍在射程內的地空目標各受 1 傷害，沿最多 3 格的可行路線，選擇「走回家距離」最遠的落點；相鄰格不受影響。地面敵人以 BFS 到家的距離判斷遠近，遇牆或邊界會轉彎尋路，動畫跟隨完整折線，不穿建築。完全包圍且沒有更遠的安全位置時才留在原地。飛蟲忽略建築，以到家的直線距離選擇落點；動畫後重新尋路。攻速由 0.5 降低 30% 至 0.35 次/s，約每 2.86 秒攻擊一次。盾蟲保留格擋規則，跳蟲首次受傷優先跳躍，跳躍途中不被拉回障礙物。原選定目標先消失，氣波仍抵達發射時瞄準的格子，同次死亡分裂的小蟑螂不會被追溯攻擊。拳套的氣波在命中時消散，蟲的後退動作顯示實際路線。

暫停時，怪物、彈體、雷射、冰凍靈氣與地面火焰都會停在當前畫面。

### 簡單平衡計算

直接傷害 DPS＝每發傷害×每秒攻擊次數；每 10 枚金幣輸出＝DPS÷價格×10。這是持續命中、無格擋、無溢出傷害時的基準，不計走出射程、轉火與子彈時間。

穿透的總輸出取決於排成直線的命中數；大砲取決於爆炸範圍內的地面蟲數；火焰取決於留在火區的時間，不能把它的每秒燃燒重複疊算。控制塔的低直接 DPS 不能單獨代表弱勢。各關以可用預算實測不同陣形。

`npm run balance` 以固定出怪比較地面蟲群、空中蟲群、上盾蟲群、56 血巨蟲與混合蟲群。每塔分別單獨測量，以及搭配兩座一般塔測量額外有效傷害；只計實際扣除的血量，不把溢傷算進去。穿透使用有利的直線佈位，其餘塔在路旁，結果寫入 `dist/balance-report.json`。此為特定路線的比較，不能解讀為所有地圖的勝率；控制效果另看支援增益，超過 200 實際秒的樣本會標為未結束。

## 保存與介面

讀取部署存檔或重試時，普通城堡恢復到 5 顆心，升級城堡恢復到 6 顆心。舊存檔會沿用普通城堡。已完成第十關的存檔保留當時剩餘生命，供通關畫面顯示。

`localStorage` 使用獨立鍵 `garden-guard-v1`，存檔版本為 22。第 10 關在第 21 版加發 10 枚部署金幣，第 11 關在第 22 版加發 10 枚，各關舊存檔會補發一次。讀取第 17、18 版的已升級融合塔時，會還原為基礎融合塔並退回該顆水晶。第 17 版的石牆融合塔會在原格還原為原砲塔，保留升級、傷害紀錄與砲塔耐久上限內的血量，退回 1 金幣與 1 把融合槌。更早的版本依通關進度補上融合槌。舊存檔依已通過的關數，扣除仍裝在建築上的水晶，補足可用餘額。另以 `garden-guard-bonus-unlocked` 保留已開啟隱藏關的紀錄。部署存檔保存目前關卡和配置；戰鬥中重新整理恢復當關開戰前的盤面，過關後保存本關戰場、獎勵與各塔的實際傷害，按「下一關 →」才進入下一關部署，第十關完成的狀態也會保存，不重複發獎金。舊版先依其原有經濟換算，再扣除新舊累積預算差額一次；已購建築及其退款價格保留，現金最低為零。再次讀檔或重試不重複扣款。舊版放在新增入口的建築會全額退款。舊子波次歸零，想用新版標準預算測試可直接選關或按「解答」。

第 8 版開始，每座建築保存原購買價 `paidCost`，拆除退回實際支付的完整金額，撤回及重試也保留該價格。讀入第 7 版以前的塔按調價前價格處理：例如舊電漿塔退 14、舊火焰塔退 10，第九版購買的電漿塔退 32、火焰塔退 8，第 10～12 版新買的則分別退 22、7。第 13 版起電漿塔售價為 18。舊隱藏關存檔移到新版地圖時，中央城堡和新入口占用的建築會退回造價與投入的水晶。調整售價不會額外向舊盤面收費，也不會因讀檔把退款改成新售價。

棋盤會依畫面可用寬高等比例縮放，保留四邊入口。手機直向的八種建築排在棋盤下方，橫向且畫面較矮時改排在右側。右上角的顯示設定可切換「顯示蟲蟲進攻路線」和「顯示蟲蟲血量」。操作按鈕至少 48px。過關時彈窗顯示本關金幣和一顆升級水晶，按「部署」後可繼續佈陣。

支援方向鍵移動格子、Enter／空白鍵放置、Tab 聚焦、Escape 取消。切換分頁自動暫停。沒有連線、登入、成績後台或強制雙人輪流；教育內容融入數字減法、預算、方向、地空分類與最短路徑。

### 花園美術

七種砲塔、石牆、十三種蟲和彈體共用 `art.js` 的向量圖。工具列、放置預覽和戰場使用同一套塔圖。每隻蟲的體型由出生時的生命值決定，初始生命越高，體型就稍大，低血量小蟲約半格，高血量常規蟲接近一格，蟲王連大顎則超過一格。受傷時體型固定，血量數字會更新。蟑螂卵由一簇青綠色蟲卵組成，從正上方可見每粒圓卵的胚點和透亮卵膜，滾動時前後交替，陰影落在卵粒交疊處。卵團破裂時小卵殼四散，小蟑螂沿拋物線彈出。血量數字固定字級，蟲群靠近時會在蟲身上下錯開。花園背景為 `garden.webp`，建置時會隨樣式嵌入網頁和離線單檔。

砲塔射出小圓彈，大砲沿弧線拋出較大的鐵球，火球投石機沿高拋物線擲出帶火紋的岩塊，岩塊獨立翻轉，貼身火焰隨氣流彎曲，升級後岩塊直徑為普通版的 1.8 倍，電漿塔則有帶電弧的大電漿球。彈體在開火時固定落點，飛行中沒有尾跡或地面投影。寒冰石向四周釋放靈氣，雷射砲以發光鏡頭射出一道紅色光束。冰圈從水晶下方擴開，拳套會伸出再回彈，普通電漿塔瞄準時，電流沿銀色線圈爬升；升級後兩側紫晶電極交叉放電，匯入頂端光球，充滿後從球頂射出電漿。雷射在實際命中的位置冒出火花。血量數字在特效上方，暫停會凍結戰場動畫。蟲攻入城堡時，城垛上方會浮出裂成兩半的紅心。過關時最後一次攻擊仍能播完，下一波等玩家按下按鈕才開始。

## 驗證

`npm test` 包含戰鬥機制、尋路、盾甲、地空判定、十關累積預算通關、無牆及單一塔種對照、獎金一次性、部署凍結、保留建築、每關生命補滿、單塔退款、重試、舊存檔和全程完成存檔。`tests/layouts.cjs` 直接引用 `solutions.js`，驗證按鈕所使用的主線及隱藏關解答。

瀏覽器測試直接開啟本地單檔，也可用 `GARDEN_URL` 指定伺服器。使用隔離進度，不更動使用者存檔。

```powershell
npm run build
$env:PLAYWRIGHT_PATH = '既有 Playwright 套件的絕對路徑'
npm run test:browser
```

Windows 預設使用已安裝的 Edge，可用 `CHROME_PATH` 覆寫。測試涵蓋前兩關正常推進、最後一關實戰及結算保存、退款重佈、選關、暫停、十二種蟲能力、八種建築資訊、鍵盤、觸控、1440／900／390／320px 與 200% 縮放。畫面輸出到忽略的 `dist/browser-check/`。`npm run test:auto-waves` 可單獨執行關卡流程驗證。

`npm run test:controls` 驗證冰凍全體只緩速、藍色蟲身、雷射砲口對齊、單格擊退沿路遠離家、電漿塔瞄準線跟隨與暫停、1.5 秒後射擊及整數傷害資訊。邏輯測試另檢查範圍邊界、盾甲、原目標消失、死亡分裂、障礙物、穿透慢攻速、電漿塔對第八關巨蟲的逐發扣血，以及新舊售價退款。

`npm run test:solutions` 驗證一般網址、`tip=false`、`tip=1` 及 `tip=True` 都沒有解答按鈕，並在 `tip=true` 下驗證十關及解鎖後的隱藏關解答都能通關、價格不超過預算、按鈕清空舊盤面、戰鬥與暫停重設、儲存恢復、入口箭頭與 1440／390／320px 按鈕可用性。

三王初版的逐關剩餘愛心、192 組封塔抽測、24 種蟲王入口與各塔升級結果收錄於[三王關卡與砲塔實測](reports/三王關卡與砲塔實測.html)。
