# 傻瓜勇者

H5 程式邏輯遊戲：先走到寶劍那格拿劍，再站在怪物的上、下、左或右一格攻擊，最後走到出口。首頁直接玩單人；「一起玩」可建立房間或加入同一區網的隊伍。

## 公開單人 H5

[開始玩傻瓜勇者](https://scozirge.github.io/a-thought/foolish-hero/) · [第四次課程目錄](https://scozirge.github.io/a-thought/hatchbeasts/classroom/#fourth-course)

公開版開啟就能玩，不需伺服器或登入；隱藏連線、討論與分工設定。四個關卡、清空、失敗重置、半秒播放與自訂地圖皆可使用。

執行 `npm run build:h5`，會在 `dist/h5/` 產生靜態單人版。沿用本專案 GitHub Pages：將輸出放到 `gh-pages` 分支的 `foolish-hero/`，保留其他遊戲目錄。所有資源使用相對路徑，支援子目錄部署。

## 啟動

需要 Node.js 20 以上，不需安裝套件。

```powershell
cd D:\Projects\AThought\joylings\minigame_design\robot-relay
node server.mjs
```

也能雙擊 `啟動遊戲.cmd`，開啟 http://localhost:4317/。保持伺服器執行即可。設定 `PORT` 可改連接埠；房間與討論訊息保存在記憶體，重啟後會消失。

## 單人玩法

1. 點指令，會自動放入下一個空格。也可先選格子再放指令，或拖曳指令進格子。
2. 「清空」清除自己的全部未送交指令；格子旁的 × 只清一格。
3. 填好後按「出發」，每 **0.5 秒**執行一步。房主／單人玩家可暫停與繼續。
4. 怪物擋路，拿劍後才能攻擊；斜角不能攻擊。打敗怪物後出口才開啟。多出的格子用「等待」。
5. 失敗會立即清空所有玩家的答案和草稿種子，保留出錯位置與原因。按「再試一次」回到起點、重新作答。
6. 「換關卡」可選題；「看提示」顯示路線與文字提示。成功時按「下一段冒險」選下一關。

內建關卡只需 6～8 步，指令排成兩列。第一關其中一個答案：向右、拿劍、向上、攻擊、向右、向上。

| 關卡 | 難度 | 地圖 | 最短指令數 | 思考重點 |
| --- | --- | --- | --- | --- |
| 森林的入口 | 先後順序 | 4 × 4 | 6 | 先拿劍、再攻擊、最後到出口 |
| 拿劍再回頭 | 回頭思考 | 4 × 4 | 7 | 取劍後回到原來的位置 |
| 繞過小石牆 | 繞路練習 | 4 × 4 | 8 | 拿劍後繞過一面牆 |
| 左邊的城門 | 換個方向 | 4 × 4 | 8 | 向右拿劍，再往左邊的出口走 |

## 連線與分工

- 「一起玩」→「建立房間」，從房間視窗複製連結。其他電腦需和房主同一 Wi-Fi／區網，使用房主電腦的區網位址；不可在其他電腦用 `localhost` 指向房主。
- 同一電腦測試可用「開隊員分頁」。每個分頁有自己的加入資訊，重新整理會恢復連線。
- 房主按「開始本題」的瞬間才鎖定在線參與者。只有房主也能玩，全部指令由房主完成。
- 最多 1 位房主、6 位隊員，整題不超過 8 步。隊員各負責 1 或 2 步，剩餘步驟歸房主；人多時自動減少個人步數，房主至少保留 1 步。6 步關卡遇到 7 人時只補 1 格等待，讓每人都能參加。
- 晚加入者可觀戰和討論，下一題才參加；不改當題指令或送交門檻。本題參與者全部送交後自動同步播放。
- 「隊伍與討論」提供文字訊息和房主踢人。作答中踢人只把該隊員步驟轉交房主，其餘人的答案保留；房主須補齊並重新送交。播放中踢人不改已排好的指令。
- 被踢者會退出房間，舊 token 立即失效。無帳號 demo 仍允許用新身分加入，但當題只能觀戰。
- 斷線不重分配當題步驟，可重連接續；房主也能踢出離線者接手。
- 失敗後「再試一次」視為新題開始：清空答案、回到起點，按此時在線人數重新分工。

若 Windows 阻擋其他電腦連線，需允許 Node.js 通過私人網路防火牆。程式不自行修改防火牆。跨網際網路多人連線需另外部署；公開 H5 提供單人模式，本地多人功能保持不變。

## 自訂題目

「換關卡」→「自訂題目與分工」可設定每位隊員最多 1／2 個指令，並以工具修改起點、寶劍、怪物、出口和石牆。內建關卡都是 4 × 4 地圖，已移除額外加步數的選項。

遊戲驗證位置不能重疊、不能放在牆上，且必須有可通關的路線。用 BFS 搜尋最短步數；自訂關卡超過 8 步時，畫面與伺服器都會拒絕開題。實際判定接受任何符合規則的解法。

## 介面與技術

主畫面只有目標、地圖與指令；關卡設定、連線及討論收進視窗。繁體中文，無倒數、無音效，提供減少動畫、鍵盤、點擊與拖曳操作；窄螢幕開始播放時會移到地圖。

- `public/`：原生 HTML、CSS、JavaScript、原創 SVG 場景與角色，無 CDN／外部素材依賴。
- `public/game.js`：前後端共用規則、關卡、求解器、分工、`STEP_MS = 500` 與 `MAX_STEPS = 8`。
- `server.mjs`：Node.js 原生 HTTP 與 SSE。伺服器管理身份、分工、送交與播放。沒有資料庫、帳號或語音。
- 房號供加入，私人 token 控制分頁權限；房間無連線且閒置 4 小時後清除。適用可信任區網的教學 demo。
