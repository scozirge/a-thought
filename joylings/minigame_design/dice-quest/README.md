# 骰子魔法冒險

第六週候選遊戲的本地試玩版。借用 Dicey Dungeons「把骰子用在裝備上」的玩法方向，使用自行設計的角色、SVG、卡片、戰鬥數值與關卡。未使用原遊戲素材，未發布或加入正式課程。

## 核心玩法

三場回合戰鬥。拖骰子到魔法卡，或點骰子再點卡。每張卡、每種工具每回合各用一次；用完按「結束回合」讓敵人攻擊，再得到新骰子。敵人下一招會預告，沒有操作倒數。

- 火球：點數 >4，造成點數 ×2 傷害。
- 冰箭：點數 <4，造成點數 +2 傷害，敵人當回合攻擊 −3。
- 光劍：任意點數，造成等量傷害。
- 護盾：任意點數，獲得點數 ×2 的護盾，只擋本回合。
- 治癒：點數 =3，恢復 6 點生命，不超過上限。
- 加一點：骰子 +1。
- 偶數平分：一顆偶數骰子變成兩顆一半點數的骰子。
- 合併：選兩顆骰子，合為一顆總和骰子。可大於 6。

懸停卡片可預覽選中骰子的運算結果。非法操作不消耗骰子或卡片；右鍵、Esc 取消選擇。「撤回」可撤回本回合的動作，結束回合後不能倒回。

## 三場戰鬥

1. 莓果史萊姆：生命 34，輪流攻擊 6、8、10。
2. 鐵甲蟹：生命 46，每次傷害扣 3，攻擊 7、11、9，鼓勵合併集中傷害。
3. 雷角龍：生命 64，單次傷害 >12 時反彈 3。蓄力、攻擊 18、攻擊 10 循環，鼓勵考慮冰箭、防守與反彈。

反彈在致命攻擊仍會發生；同時倒下判定失敗，可以重試當場。護甲先扣除，雷角龍以該次攻擊傷害判斷是否反彈。

每場勝利選一個強化並恢復 8 點生命（生命果實回滿）。第一場選火球增傷或冰箭加強；第二場選生命上限增加或每回合多一顆 1。生命延續到下一場；失敗可回到當場開場狀態。

回合骰子以 `[2,4,6]`、`[1,3,5]`、`[2,5,6]`、`[2,4,5]` 循環，讓重試能比較策略，不因運氣重抽而改變結果。動畫是發骰子的視覺效果，非真實隨機擲骰。

## 儲存與啟動

獨立 localStorage `dice-quest-v1` 保存當前戰鬥、強化與回合。動畫完成前重新載入會回到最後已儲存動作；不影響其他遊戲存檔。無帳號、排行榜或強制雙人輪流。

```powershell
npm start
npm test
npm run build
```

本地網址：`http://127.0.0.1:18122/`，靜態輸出 `dist/h5/`。純 HTML/CSS/JavaScript，無需安裝依賴。

## 驗證

`npm test` 檢查卡片條件、工具、護甲、反彈、回合防禦、強化與存檔，並搜尋兩條不同強化路線，確認三場都能通關。這只能確認可解性，實際趣味與兒童難度仍需試玩。

`node tests/browser.cjs` 使用獨立 Playwright 瀏覽器，檢查拖曳、點選、觸控、撤回、儲存、重試與完整通關，以及 320、390、900、1440 像素版面。需要另外提供 Playwright；可用 `PLAYWRIGHT_PATH` 指向既有套件、`CHROME_PATH` 指向 Chrome。截圖輸出至忽略提交的 `dist/browser-check/`，不修改使用者瀏覽器的存檔。
