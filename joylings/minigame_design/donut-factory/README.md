# 甜甜圈運算工廠

第六週候選遊戲，本地三關試玩。0.2 改為六年級運算挑戰，保留甜甜圈與機器加工的視覺，路線固定，由玩家選擇運算與判斷。使用自行繪製的 SVG 與自訂關卡；未使用原遊戲素材。尚未加入正式課程或發布。

## 玩的方法

- 拖機器到空位，也可點機器自動放入第一個相符空位。替換時先點空位再點機器。
- 已放好的機器可拖曳交換位置。比較機器只能放在判斷處。
- 按「試跑」依序驗證全部訂單。甜甜圈沿產線移動，顯示每次運算、目前值、分支與最終結果。
- 選中機器後 Delete 移除；「上一步」復原編輯；「重來」清空本關；右鍵取消選取，Esc 停止執行。
- 中途分數與負數可以繼續運算；使用精確分數，最終結果必須等於每筆訂單的目標。允許不同等價解法。
- 切關、改機器會中止舊動畫，保留已通關勾勾。新版使用獨立存檔 `donut-math-v2`，不把畫線關卡的勾勾當成運算關卡已完成，不修改舊存檔。

## 關卡

1. 破解順序：從 4 組輸入／輸出找出 3 台機器的順序，包含除法與乘法。
2. 差距放大：計算 X 與 8 的差距再乘 3，共 5 張訂單，含小於、等於、大於。
3. 雙盒密碼：先合併 X、Y，從 6 張訂單推理兩條加工路線，測試總數等於門檻的分支。

元件包含加減乘除、反向減法、讀取 Y，以及大於／小於／等於、如果／否則。難度來自運算順序、共用規則與邊界條件，沒有倒數、步數評分或強制兩人輪流。

## 啟動

```powershell
npm start
npm test
npm run build
```

本地：`http://127.0.0.1:18121/`。靜態輸出：`dist/h5/`，不用安裝套件。

`tests/browser.cjs` 使用環境已安裝的 Playwright 與 Chrome，在隔離進度中驗證拖曳、交換、點選、運算、存檔與畫面尺寸。
