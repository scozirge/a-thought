# 全武器訓練場

2026-10-01。連線版本 `rivals-web-20-training`；依使用者最新要求，本次及後續僅發布 Web 版。現有 Windows 成品保留為舊版本。

## 功能與隔離

- 主選單下方新增「訓練場」。使用 Fusion `GameMode.Single`，不建立公開房間；遊戲載入完成後，即使房間清單連不上也可進入。
- 獨立場地包含射擊線、距離標線、七個固定人形靶，以及九個武器拾取站。靶子不移動、不還擊，皆可被玩家攻擊。
- 「更換武器」選單涵蓋手槍、步槍、散彈槍、狙擊槍、加特林、無限火箭、核彈、菜刀、劇毒藥水。可重新領取同種武器並補滿彈藥。
- 武器傷害、射速、散射、換彈、拋物線、範圍自傷及核彈七秒倒數使用正式戰鬥程式。
- 自己與靶子死亡三秒後自動復活。靶子回原站位；玩家回射擊線、恢復 300 生命及所選武器滿彈藥。單次武器仍在使用後切回手槍，可透過選單重新領取。
- 訓練擊倒數可超過 30，沒有勝負展示或時間限制。離開後恢復正常場地、紅藍分隊與 Bot 行動；武器選單命令在一般對戰中無效。
- 小尺寸橫向手機將「更換武器」移至下方中央，保留玩家名字的寬度。關閉選單時攔截跨按鈕的觸碰合成 click，避免穿透後誤觸暫停。
- 場內文字使用有深度測試的專用 Shader，避免距離與靶位標示穿透角色和牆壁。

## 驗證

- 編輯器實際 Fusion 訓練場：35 項檢查通過，涵蓋單人模式、九種武器、靶子靜止、自己與靶子三秒復活、選定裝備恢復、超過 30 次擊倒、退出與重入。
- 既有 `BattleRulesChecks.Run -battleSmoke` 通過，保留一般對戰、30 擊殺結束及隨機復活規則。
- `MobileBridgeChecks.cjs`：14 組觸控輸入回歸通過。
- `MobileLayoutChecks.cjs`：Chromium／WebKit 共 14 個既有操作版面通過。
- 最終正式 Web 實測：25 組鍵鼠／手機檢查通過，九種武器皆實際攻擊；核對固定靶擊倒與復活、飛刀、火箭自傷、毒區、核彈延遲和玩家復活。手機在載入完成後切成離線，仍可進入、遊玩、離開與重新進入。訓練後建立正常多人房間，確認紅藍各四人、Bot 正常移動，且訓練場換武器命令無法在對戰中使用。
- 最終 Web 視覺檢查：8 個桌機／手機尺寸通過，包含 568 × 260 短橫向畫面、直向手機與長名字，核對名牌可讀性、HUD 邊界及按鈕重疊。
- 訓練場選單：Chromium／WebKit 共 12 組檢查通過，涵蓋九種武器觸碰選取、主選單下方入口、連線等待時仍能進入訓練場，以及關閉選單不會穿透誤觸其他按鈕。
- 一般多人連線回歸：在 WebSocket 每個方向增加 90 毫秒延遲下，12 組真實 Photon 雙人檢查通過，包含手機／桌機互相開房加入、移動與射擊同步、點按瞄準、全螢幕、失焦復原、退出與切換操作模式。
- Unity Web Release／IL2CPP 正式建置通過；教學 H5 建置與 301 處資源引用檢查通過，教學遊戲入口更新為 `?v=training-20261001`。

`Tools/TrainingMenuChecks.cjs` 測試實際網頁選單、武器按鈕及手機觸碰；`Tools/WebTrainingSmokeTest.cjs` 使用正式 Web、一般選單與攻擊輸入，不修改角色、位置、生命或計時器。`Tools/WebVisualSmokeTest.cjs --training` 檢查正式訓練場 HUD 與手機按鈕的邊界及重疊。

測試是瀏覽器觸控模擬，尚未使用 Android／iPhone 實機。
