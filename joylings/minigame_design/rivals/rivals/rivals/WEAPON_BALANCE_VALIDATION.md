# 武器平衡與操作修正

2026-10-01，連線版本 `rivals-web-21-balance`，僅發布 Web 版。

## 本次調整

| 武器 | 更新內容 |
| --- | --- |
| 劇毒藥水 | 投擲方向初速 8 → 16、向上助力 4 → 5；毒區半徑 4 → 6 公尺，區內移速降低 40%，離開或毒區結束即恢復；仍持續 5 秒、每半秒 30 傷害，自己與隊友也受影響。 |
| 毒區特效 | 移除紫色內圈，保留綠色毒液、綠色邊界、氣泡和危險標線；畫面顯示中毒緩速提醒。 |
| 菜刀 | 飛刀初速 24 → 32；保留拋物線、命中一刀擊倒及投出後換回手槍。 |
| 核彈 | 成功標記後立即換回手槍；訓練場復活也保持手槍，需要重新選取核彈才能再用。無效的天空標記不消耗核彈。 |
| 加特林 | 每發傷害 12 → 24，換彈時間 6 → 12 秒；射速、100 發彈匣和散射機制不變。 |
| 狙擊槍 | 爆頭 300 傷害，滿血一槍擊倒；身體仍為 150，每發裝填 2.2 秒。 |
| 無限火箭 | 每次新按下才發射一發，按住不連發，冷卻中的點擊不排隊；初速 13 → 10、向上助力 5 → 3.5，縮短射程；保留 4 秒冷卻和原有爆炸傷害。 |

緩速與傷害共用毒區範圍、地板高度及遮擋判定，重疊毒區不疊加緩速或傷害頻率。移速計算使用同步中的毒區，適用房主與客戶端預測，並會影響衝刺及持刀加速後的速度。
