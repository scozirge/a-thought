# 復活武器預設與倒數改選驗證（2026-10-01）

## 本次規則

- 每次死亡都預設最近解鎖的武器；尚未解鎖特殊武器時使用手槍。
- 復活倒數可改選手槍或其他已解鎖武器，只影響當次復活。下次死亡會重新預選最近解鎖的武器。
- 場地拾取的步槍、散彈槍、狙擊槍不加入復活選單，也不改變復活預設。
- 當次答題解鎖新武器，立即以新武器作為即將復活的預設。同房下一場保留解鎖進度，重新預選最近解鎖武器。
- 全部解鎖後直接進入倒數，仍可改選；離開房間後清除解鎖進度。
- 倒數介面沿用既有武器按鈕，不增加說明文字。

房主在死亡及同房新局開始時，從解鎖進度計算預設。倒數選擇仍由房主檢查生命編號、死亡狀態、倒數階段及解鎖資格，不新增網路欄位。連線版本改為 `rivals-web-26-respawn-default`，避免舊房主沿用舊規則。
