# 復活武器預設與倒數改選驗證（2026-10-01）

## 本次規則

- 每次死亡都預設最近解鎖的武器；尚未解鎖特殊武器時使用手槍。
- 復活倒數可改選手槍或其他已解鎖武器，只影響當次復活。下次死亡會重新預選最近解鎖的武器。
- 場地拾取的步槍、散彈槍、狙擊槍不加入復活選單，也不改變復活預設。
- 當次答題解鎖新武器，立即以新武器作為即將復活的預設。同房下一場保留解鎖進度，重新預選最近解鎖武器。
- 全部解鎖後直接進入倒數，仍可改選；離開房間後清除解鎖進度。
- 倒數介面沿用既有武器按鈕，不增加說明文字。

房主在死亡及同房新局開始時，從解鎖進度計算預設。倒數選擇仍由房主檢查生命編號、死亡狀態、倒數階段及解鎖資格，不新增網路欄位。連線版本改為 `rivals-web-26-respawn-default`，避免舊房主沿用舊規則。

## 實際瀏覽器連線

- `WebLearningSmokeTest.cjs`：40 項通過。兩個隔離的 Chrome 玩家經 Photon 建立／加入真實房間，以一般移動、Bot 攻擊與畫面按鈕完成死亡及答題；沒有在成品加入測試用狀態修改入口。
- 玩家實際答對三題解鎖菜刀，下一次死亡倒數改選手槍並持手槍復活；再死亡時房主和玩家都恢復菜刀預設，實際復活也拿到菜刀。
- 倒數只顯示手槍與已解鎖菜刀；透過與按鈕相同的指令請求步槍、散彈槍或狙擊槍，均被房主拒絕。重複送答案不增加徽章，離房重入清除進度。
- `WebTrainingSmokeTest.cjs`：37 項通過，鍵鼠與觸控皆涵蓋全部武器、毒區、核彈死亡復活及返回一般對戰。
- `WebMobileSmokeTest.cjs --lag --respawn`：13 項通過，雙向各增加 90 ms 延遲，驗證手機／電腦互相建房、操作同步、實際死亡答題與三秒復活，無殘留移動或開火。
