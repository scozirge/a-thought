# 五款新武器與動態準心

2026-10-01。Unity 6000.3.11f1，連線版本 `rivals-web-19-arsenal`。遊戲程式、Web 與 Windows 共用相同規則。

## 行為

- 新增加特林、無限火箭、核彈、菜刀、劇毒藥水，原創程序式造型、武器圖示、第一人稱持握與第三人稱顯示；加特林槍管連射時旋轉。
- 加特林 100 發、0.06 秒射擊間隔、6 秒換彈。連射散射會累積，停火恢復，準心間距以實際散射角、FOV 及螢幕高度換算。
- 火箭低速拋物線、4 秒間隔；直擊 300、爆心 3 公尺內 150、6 公尺內 100，同一角色只計一層傷害，掩體會阻擋爆風。
- 核彈標記有效地點後立即換回手槍，14 公尺紅圈閃爍並顯示撤離倒數；7 秒後落彈，範圍內全員死亡，掩體無法阻擋。看天空不會消耗核彈。
- 菜刀持有時移速增加 30%，2.5 公尺內揮砍 300 傷害；右鍵或手機「飛刀」是實際投射物，命中 300，丟出後換回手槍。
- 毒液短距離拋物線、3 秒間隔；落地 4 公尺毒區維持 5 秒，每半秒扣 30，離開停止，重疊不加快扣血。
- 依使用者確認，火箭、核彈、毒液都傷害自己與隊友；只有擊倒敵隊會增加比分。範圍爆炸先完成同一批受害者傷害，再進入 30 擊殺勝利展示。
- 地圖共 14 個對稱拾取點。一般武器 5 秒補充，核彈 45 秒。傷害、投射物碰撞、毒區及倒數由房主判定；同步保留原攻擊者姓名／隊伍／武器，換槍或離線不會改寫歸屬。
- 手機依武器切換攻擊按鈕，隱藏不適用的瞄準及裝填鍵；無限武器顯示冷卻秒數。持續顯示自己的名字與隊伍，維持無跳躍、無滑行。

## 已完成驗證

- `RivalsPrototype.Editor.ArsenalChecks.Run -arsenalSmoke`：64 項編輯器內實際 Fusion 對戰檢查通過，涵蓋拾取位置與對稱、射速／彈數／換彈、散射恢復、拋物線飛行與碰撞、直接及範圍傷害、自傷／友傷、牆壁、飛刀短按、毒區持續時間與離區、核彈單次消耗與七秒延遲、30 殺爆炸批次判定、原攻擊者姓名與武器歸屬。
- `RivalsPrototype.Editor.BattleRulesChecks.Run -battleSmoke`：既有戰鬥回歸通過，保留散彈／狙擊／步槍、拾取、死亡三秒倒數、隨機復活、舊生命封包隔離、30 擊殺勝利、賽後重分隊等行為。
- `Tools/MobileBridgeChecks.cjs`：14 組瀏覽器輸入檢查通過，含真正多指觸控、按一下瞄準、飛刀短按、武器切換清除瞄準、死亡清除輸入、全螢幕及失敗降級。
- `Tools/MobileLayoutChecks.cjs`：Chromium 與 WebKit 各 7 種視窗／安全區，共 14 個版面檢查通過。
- 編輯器輸出的五款造型與遊戲內毒區、核彈標記已人工檢視。特效使用獨立的透明 Shader，避免多層特效把地形完全遮住。

- Web 與 Windows x64 正式建置成功，均為非 Development Build。
- `Tools/WebArsenalSmokeTest.cjs`：兩個隔離的 Chrome／Photon 玩家實際撿取並使用全部五款新武器；確認訪客攻擊、房主射擊數／武器同步、加特林散射與裝填、毒區雙端顯示、核彈七秒警示至雙端爆炸、單次武器返回手槍、原投擲者姓名。
- `Tools/WebVisualSmokeTest.cjs`：正式 Web 的 8 種桌面／手機視窗通過；名字、隊伍、血量與彈藥都在視窗內，與觸控按鈕不重疊。
- `Tools/WebMobileSmokeTest.cjs --lag`：WebSocket 雙向各增加 90 ms 延遲，12 組實際 Photon 操作檢查通過，包括多指移動／轉向／射擊、六次短按與雙端彈數、裝填、點按瞄準後邊轉向邊攻擊、衝刺、全螢幕、選單、失焦、手機建立房間、離房與 Bot 補位。此回測得短按本機回饋最長約 54 ms，不代表所有實機或網路的效能。
- `Tools/ReleaseCrossPlaySmokeTest.cjs`：正式 Windows 房主＋Web 訪客，以及 Web 房主＋Windows 訪客均通過；房主離開返回大廳、Windows 訪客離開由 Bot 補位亦通過。
- 教材 H5 重新建置並通過 301 個資源引用檢查，「玩紅藍槍戰」改連 `?v=arsenal-20261001`。

首次延遲操作測試接手了已撿核彈的 Bot，原有測試假設手槍朝天空射擊，因核彈拒絕無效地面標記而逾時。測試改在開場倒數加入，明確驗證手槍起始條件，重跑後通過；中途加入保留 Bot 武器的正式行為未更改。

手機瀏覽器模擬不等同 iPhone／Android 實機測試。正式產物與 GitHub Pages 的逐檔核對結果記在包內版本資訊、SHA-256 清單，以及這次發布提交中。

## 重現

編輯器入口 `ArsenalChecks.Run` 先輸出武器圖示、再進入測試場景；需加 `-arsenalSmoke`，不要加 `-quit`，測試結束會自行回報退出碼。測試控制只存在 `UNITY_EDITOR`，正式成品未提供血量、武器、位置、比分或計時器的修改介面。

`Tools/WebArsenalSmokeTest.cjs` 使用兩個獨立瀏覽器透過正常大廳、鍵盤與滑鼠，實際撿取及發射五款武器，讀取既有診斷資訊確認訪客與房主同步。可用 `RIVALS_WEB_URL`、`RIVALS_TEST_OUTPUT` 指向待測正式輸出並保存截圖。
