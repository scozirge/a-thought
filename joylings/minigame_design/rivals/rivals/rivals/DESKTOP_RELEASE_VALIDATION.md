# 電腦正式版與連線驗證（2026-10-01）

發布批次 `desktop-release-20261001`；連線版本 `rivals-web-27-shot-feedback`。範圍為電腦 Web 網頁版，保留手機操作、三顆星及第三次課程。

## 測試發現與修正

本次舊版一般雙人連線通過，但雙向各增加 90 ms 延遲時重現射擊效果重複：實際 `shots=9`、`visualShots=10`，彈藥為 3。未將這次失敗當成通過，先修正再重建候選版。

舊程式只以 `Runner.IsForward` 決定是否播放本機射擊效果。Fusion 會先回復伺服器狀態，再重算預測與後續 tick；同一次按鍵的射擊若移到新的 forward tick，單靠這個旗標不能識別已播放事件。[Photon Fusion 更新順序](https://doc.photonengine.com/fusion/v2/concepts-and-patterns/fusion-update-loop)

修正以生命、主／副攻擊按鍵序號及本次按鍵的連射序號識別射擊；連射序號跟隨網路狀態重算，已播放紀錄留在本機。重算同一發不再播放效果，新按鍵即使遇到總射擊數回退仍能立即回饋。傷害、射速與彈藥規則沒有調整。因新增同步欄位，連線版本更新，所有玩家需重新整理後再同房。

- `ShotFeedbackChecks`：16 項通過，包含重複 forward、計數回退後的新按鍵、按住連射、主／副攻擊獨立、復活與過期生命。
- Unity 教學整合：256 項通過，完整 15 題、五階段解鎖、錯題重問、重複及過期請求、當次倒數選擇、下一次預設最近解鎖、一般拾取武器排除、同房保留與離房重置。
- Unity 戰鬥整合：796 項通過，包含武器傷害／裝填／散射、拾取、出生遮擋、64 次隨機復活、舊生命輸入隔離、30 擊殺勝負、頒獎與下一場。
- 答題介面：72 組通過；訓練選單：Chromium／WebKit 共 12 組通過；滑鼠鎖定與 iframe 相容：8 組通過；CDN 雜湊、備援與快取路由：16 項通過。
- 課程 H5 建置成功，335 個資源引用通過；課程入口檔通過 lint。

## 測試工具整理

電腦焦點測試另重現：按全螢幕後已進入全螢幕，但沒有重新鎖定滑鼠。修正於同一次按鍵先請求 Pointer Lock，再請求全螢幕，並恢復畫布焦點；避免全螢幕先消耗使用者操作授權。[MDN Pointer Lock 呼叫順序](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestPointerLock)

`Tools/ValidateWebRelease.cjs` 增加 `desktop-ui`、`desktop`、`network-stress` 分組。延遲壓力檢查包含四輪共 32 次短按、輪間裝填與按住連射，檢查兩端射擊數、呈現數與彈藥。

舊版鍵鼠與準心腳本改為接受共同的測試網址和輸出目錄，方便整理紀錄。訓練選單隔離測試補上外部 JavaScript／CSS 的正確回應，避免將載入輔助程式誤回傳為 HTML。
