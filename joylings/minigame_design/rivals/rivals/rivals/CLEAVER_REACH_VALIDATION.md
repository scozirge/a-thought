# 菜刀距離與尺寸更新

日期：2026-10-01。發布目標：Web，連線版本 `rivals-web-24-learning`。

[直接玩最新版](https://scozirge.github.io/a-thought/rivals/?v=learning-20261001) · [課堂教學](https://scozirge.github.io/a-thought/hatchbeasts/classroom/red-blue-battle/)

## 本次調整

- 菜刀近砍判定距離由 2.5 公尺加倍至 5 公尺，真人與 Bot 共用同一距離常數；命中仍由房主判定。
- 菜刀模型以握柄為中心放大 25%，第一人稱、其他玩家手上的刀、地面拾取與飛刀都使用相同造型。手掌與前臂維持原尺寸，握持位置不漂移。
- 保留右上往左下的斜劈，稍微降低第一人稱抬刀高度，讓放大後的刀尖留在畫面內。
- 維持一刀 300 傷害、0.6 秒攻擊間隔及牆壁阻擋；飛刀用完仍拿回手槍。
- 更新連線版本，避免不同近砍距離的客戶端混入同一房間；教學頁遊戲入口同步更新。

## 驗證

- Unity 武器測試：`RIVALS_ARSENAL_SMOKE_OK checks=75`。實際驗證 3 公尺及 4.9 公尺能近砍擊倒，5.1 公尺不受傷，並確認較遠目標在牆後仍安全。
- 六張動作預覽完成，已檢視放大刀身的待機、抬刀及落刀畫面。
- Web 正式整合版（`Builds/Learning/Web`）：鍵鼠與手機觸控共 **12 項通過**，涵蓋斜劈、連續攻擊、收刀、目標復活、5 公尺內外命中邊界及飛刀後恢復手槍。獨立菜刀建置亦通過相同 12 項。
- 獨立菜刀版本的兩名 Photon 真人客戶端完成 **2 組連線檢查**：拾取、右上至左下斜劈與收刀、飛刀及切回手槍皆同步至房主。測試導航接近目標時改用短步，避免菜刀加速跑過指定位置造成誤報；到點容差與遊戲邏輯不變。
- 與同日課堂答題功能共用 `rivals-web-24-learning` 及教學入口，避免覆蓋另一項已完成的功能。

手機使用 Chrome 觸控模擬環境，未以 Android／iPhone 實機測試。
