# 視覺調整（2026-09-23）

目標為接近 RIVALS 的明亮競技場、方塊角色和預設武器輪廓；目前涵蓋已實作的五種武器，不包含全部原作皮膚或地圖。

| 項目 | 本次調整 |
|---|---|
| 角色 | 方塊四肢、圓柱笑臉、帽子／髮型、8 組膚色服裝搭配；藍紅背心識別隊伍 |
| 步槍 | 橘黑槍身、深色彈匣、槍托、導軌及圓形瞄具 |
| 手槍 | 黑色滑套與握把、縮短持槍距離 |
| 短刀 | Toon Shooter Knife_1 銀色刀刃與黑色刀柄 |
| 霰彈槍 | 深色槍身與側掛紅色彈殼 |
| 狙擊槍 | 綠色槍托／槍身、黑色槍管與瞄準鏡 |
| 場地 | 白灰格線、格角十字、門框掩體、側梯和高台 |
| 介面 | 由實際模型渲染的武器圖示、綠色生命條；保留簡單繁中流程 |

FBX 轉向會保留匯入模型原始旋轉，避免覆蓋原始軸向後讓武器側躺。角色、格線、細節與第一人稱手臂由本專案產生，模型來源及授權見 `FREE_ASSETS.md`、`ASSET_CREDITS.txt`。
