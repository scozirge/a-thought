# 武器邏輯挑戰驗證

日期：2026-10-01。僅更新 Web 正式版，Windows 歷史成品保留。

## 功能

- 固定 15 題、五組各三題；沿用討論定稿的題目、選項、答案與簡短解釋。
- 每次死亡只接受一次答案；答錯無徽章、下次原題重出。每三題解鎖菜刀、火箭筒、毒藥、加特林、核彈。
- 答題與閱讀解釋期間不自動復活，按繼續後才開始三秒倒數。新解鎖武器自動選取，也可選其他已解鎖武器。
- 全部解鎖後不再出題；同房下一場保留，離房重入清除。房主判定進度與武器資格，鎖住的特殊武器無法由地圖拾取。
- Bot 維持三秒復活；答題中離線的玩家由 Bot 接手時，也不會卡在無限等待。
- 訓練場保留自由領取所有武器。手機題目將滑鼠左鍵轉成射擊按鈕。
- 課程目錄新增「武器邏輯挑戰」，課程頁可展開正確答案與說明。課程 JSON 與 Unity 資源 JSON 由測試核對一致。
