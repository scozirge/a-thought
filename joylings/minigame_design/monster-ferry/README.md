# 怪獸渡船

經典過河問題的本地 H5 改編。五關分別練習雙人船、單人船、載重、守護石與綜合規則。自製 SVG 角色，原生 HTML/CSS/JavaScript，無執行依賴；不修改既有遊戲或正式課程。

## 啟動與輸出

```powershell
npm start
npm test
npm run build
```

本地網址 `http://127.0.0.1:18124/`，靜態輸出 `dist/h5/`。

## 操作與規則

- 點目前岸邊的角色上船，點船上角色下船。船長不佔乘客座位。
- 按出發過河，到岸後自動下船。允許空船往返，按鈕會顯示「空船」。
- 船長保護所在岸邊。另一岸不能留下有衝突的角色配對。
- 火怪嚇跑毛球、毛球偷吃點心；後續加入火怪融化冰怪、冰怪凍住點心。
- 守護石留在岸上時，保護該岸所有角色。把石頭帶走後就失去保護。
- 載重關卡：火怪／毛球／冰怪重 2，點心／守護石重 1，重量上限 3；座位仍最多 2。可先搭配看重量，超重時禁止出發。
- 不安全的出發顯示衝突與短動畫，保留當前角色位置及上船選擇，不扣分。成功航行可「退一趟」；重開關卡保留完成標記。

關卡：點心郊遊（3 角色、2 座）、小船來了（3 角色、1 座）、小心超重（4 角色、2 座、限重 3）、守護石出動（5 角色、2 座）、月光渡口（5 角色、2 座、限重 3）。

## 視覺與課堂

角色上船有短跳躍；船隻沿河移動並划槳、留下水波，到岸冒小星星。角色待機、水面、魚與夜晚螢火蟲使用輕動畫。支援減少動態偏好。沒有倒數或強制趟數限制。

岸邊狀態及角色關係同時可見，讓同伴能檢查留岸組合。沒有強制輪流或其他雙人限制。

獨立 `localStorage` 鍵 `monster-ferry-v1` 保存盤面、船上角色、撤回歷史與完成標記。航行中重整回到出發前，切關／重開會取消未完成的動畫。已完成的安全到岸狀態才提交航行進度。

## 驗證

`npm test` 以搜尋驗證所有關卡有解，並檢查岸邊安全、守護石、座位、載重、撤回、空船與存檔。

`node tests/browser.cjs` 以獨立 Playwright 瀏覽器完成五關，驗證錯誤出發、超重、航行中重開、重整保存、觸控、減少動態與不同尺寸版面。可用 `PLAYWRIGHT_PATH` 及 `CHROME_PATH` 指向既有測試工具。截圖輸出到忽略提交的 `dist/browser-check/`，不更動使用者瀏覽器存檔。
