# 小工程師

Unity WebGL 課堂連線遊戲。出題者只看到一張沒有名稱的原圖，自己想怎麼描述；師傅各自在手機或電腦畫圖。一般遊玩使用同一間教室的聲音，遠端可搭配既有語音通話。

## 開始玩

1. 每台裝置都開啟[《小工程師》公開遊戲](https://scozirge.github.io/a-thought/little-engineer/)。一位玩家按「開房」，其餘師傅按「加入」。每位師傅得到一組名字與頭像，進房前點身分卡即可更換。設計容量為 1 位出題者及 20 位師傅，另留一個接手席位；實際人數受 Photon 帳號容量影響。
2. 房主先在私人螢幕選難度、預覽原圖，也可以按「換一題」。按「開始出題」才開始倒數。出題中也能換題，師傅會收到通知，畫紙、完成狀態與剩餘時間都保留。
3. 按「畫好了」會勾選並鎖住畫紙與復原，按「取消勾選」可繼續畫。每輪 180 秒，小工程師也可按「結束」。先單獨展示答案原圖 3 秒，再依加入順序，將每位師傅的作品與原圖並排展示 3 秒。當輪已離房、未勾選或交白紙的師傅也有展示時間。
4. 最後，全班停在包含原圖和所有作品的作品牆，可以不限時討論。小工程師可點選最相近的一張；只有小工程師按「下一題」後，全班才會取得新題和空白畫紙。展示途中加入或換人出題，都會跟上目前的展示進度。
5. 小工程師和師傅都能在頁首看到自己的角色、名字和頭像。同一輪從原分頁離房再加入，已送出的筆跡與「畫好了」的勾選會保留。離房後換身分再加入，全班會看到新名字和頭像。若新名字已有師傅使用，系統會另配一組並通知你。
6. 第二個人按「開房」會接手同一間教室。新出題者取得當輪原圖、倒數、成員與作品後，原出題者退回首頁，其他師傅繼續留在原房間。出題者自行按「離房」則關房。

本機版可解開 `Builds/shape-studio-web.zip`，在已安裝 Node.js 的 Windows 電腦雙擊 `START.cmd`，或在專案目錄執行 `npm start`。本機網址為 `http://127.0.0.1:18136/`，同一網路的其他裝置可使用啟動視窗列出的區網網址。

## 題庫和粉筆

每種難度各有 20 張無題名原圖。同一難度抽完一輪前不重複，換出題者也會保留抽題紀錄。

| 難度 | 原圖特色 |
| --- | --- |
| 簡單 | 黑線拼成眼鏡、小屋等熟悉輪廓；零件多半大小相近，也有大框。 |
| 中等 | 熟悉的幾何造型改用粉彩線條，需要把形狀、顏色和位置一起說清楚。 |
| 困難 | 幾何形狀組成抽象圖案，靠上下、左右與相對位置來描述。 |
| 超級難 | 大小、長短與包覆關係差異明顯。 |
| 恐怖難 | 幾何搭配星星、波浪、雪人、羽毛球拍等輪廓，圖形保留少量細節。 |

師傅只用紅、橙、黃、綠、藍、紫六色固定粗細的粉筆。可自由畫或拖出圓形、方形、三角形；橡皮擦比粉筆寬。「清空」清除自己的畫紙，「上一步」能復原筆畫、擦除或清空。勾選「畫好了」時，這些操作一律鎖住。

## Unity 與 WebGL

`node scripts/setup.cjs` 從同一儲存庫的 puzzle-party 複用 Photon Fusion、Unity 套件與專案設定。`npm run build` 使用 Unity 6000.3.11f1 產生原生 WebAssembly，編輯器位置可透過 `scripts/build.ps1 -Unity <路徑>` 指定。輸出在 `Builds/UnityWeb/`，整個資料夾可複製給其他電腦或放到靜態 HTTP(S) 站台。直接開啟 index.html 無法執行 WebGL。

Unity C# 負責房間、抽題、共用倒數、筆跡與完成狀態。題圖定義在 `unity-game/Assets/Resources/chalk-cards.txt`，依序收錄五組；建置會繪出全部 100 張，檢查唯一性、配色、抽題與彩色筆跡編碼。Photon Fusion Shared 模式讓師傅在換出題者時維持連線；揭曉後師傅才取得其他人的作品。每張紙以四位元色碼儲存每個像素，共 32 KiB，傳送時壓縮空白區域。單獨展示原圖時同步收齊最後筆跡；所有裝置依 Photon 的共用時間輪播。展示順序與開始時間也會隨出題者交接，作品牆停留到手動換題。

## 連線驗證

啟動 WebGL 站台後，使用 Chrome 與 Playwright 執行 `npm run test:online`。可用 `PLAYWRIGHT_PATH` 指定既有 Playwright 模組。驗證使用全新瀏覽器環境及真正的 Photon 教室，會占用遊戲的固定房間，請於課堂外執行。

2026-11-04 已用四個獨立 Chrome 工作階段實測，包含一個手機觸控模擬。作畫和揭曉期間都能交接出題者；提前結束後，同時看得到已勾選與未勾選的作品。師傅離席、重連後的鎖筆、取消勾選、下一輪清空與三分鐘自動揭曉均通過。

五級題庫與彩色畫紙版另驗證了預覽、隨機換題、勾選後換難度仍保留筆跡、橡皮擦與清空的復原，以及出題者接手後作品牆的實際色碼。建置產生的五張題庫總覽在 `artifacts/prompts/`。

結算流程已用連線瀏覽器計時驗證：答案 3 秒、每人 3 秒、展示中加入能跟上同一張、換出題者不會重播，且只有小工程師可從作品牆開下一題。沒有師傅參加的回合直接顯示原圖。
