# 小工程師

Unity WebGL 課堂連線遊戲。出題者看原圖並口頭描述，畫家各自在手機或電腦畫圖。一般遊玩使用同一間教室的聲音，遠端可搭配既有語音通話。

## 開始玩

1. 每台電腦或手機都開啟[《小工程師》公開遊戲](https://scozirge.github.io/a-thought/little-engineer/)。使用可連上 GitHub Pages 和 Photon 的網路，房主與畫家可以在不同網路。
2. 一位玩家按「開房」，其餘玩家按「加入」。只使用同一個固定亞洲教室。每位畫家得到一組固定名字與頭像，進房前點身分卡即可換一組。名字重複時由房主分配未使用的組合。設計容量為 1 位出題者及 20 位畫家，實際人數亦受現有 Photon 帳號容量影響。
3. 房主按「開始出題」。畫家自由畫或拖出圓形、方形、三角形，可以退一步。開始後加入的人使用本輪剩下的時間。每輪 180 秒，時間到自動翻牌，作品牆顯示原圖及畫紙。房主點選最相近的作品，再按「下一輪」。全是白紙的回合也可繼續。
4. 房主用私人螢幕看題，保持遊戲分頁開著。出題者固定是房主，離開就關房。作畫期間定期備份到房主；同一分頁中斷後再加入，可以取回房主已收到的最近筆跡。作品留到該輪結束，不永久保存。

本機版可解開 `Builds/shape-studio-web.zip`，在已安裝 Node.js 的 Windows 電腦雙擊 `START.cmd`，或在專案目錄執行 `npm start`。本機網址為 `http://127.0.0.1:18136/`，同一網路的其他裝置可使用啟動視窗列出的區網網址。

## Unity 與 WebGL

`node scripts/setup.cjs` 從同一儲存庫的 puzzle-party 複用 Photon Fusion、Unity 套件與專案設定。`npm run build` 使用 Unity 6000.3.11f1 產生原生 WebAssembly，編輯器位置可透過 `scripts/build.ps1 -Unity <路徑>` 指定。輸出在 `Builds/UnityWeb/`，整個資料夾可複製給其他電腦或放到靜態 HTTP(S) 站台。直接開啟 index.html 無法執行 WebGL。

Unity C# 負責教室、身分分派、私有題目、16 張圖形卡、權限、同步截止時間、筆跡、復原與畫布繪製。WebGL 範本處理觸控、房間入口和作品牆。畫紙每張最多 8192 位元組原始資料，傳送時壓縮空白區域。揭曉前玩家只會收到自己的身分與自己的恢復資料；揭曉後按張取得作品。房主保留短暫的網路傳輸時間收齊最後筆跡，這段時間已鎖定作畫。

## 連線驗證

啟動 WebGL 站台後，使用 Chrome 與 Playwright 執行 `npm run test:online`。可用 `PLAYWRIGHT_PATH` 指定既有 Playwright 模組。驗證使用全新瀏覽器環境及真正的 Photon 教室，會占用遊戲的固定房間，請於課堂外執行。

2026-11-04 已用一位房主與兩位畫家的獨立 Chrome 環境跑完一輪。第二位畫家用手機觸控模擬，在還剩 169 秒時加入；三端在約 180 秒時看到原圖和兩張作品。另驗證房間不存在、重複開房、復原筆畫、重新加入取回筆跡、只有房主可選作品、下一輪清空畫紙及房主離開關房。這次實測為三端連線，未測滿班同時加入。
