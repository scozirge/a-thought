# 貓狗一起回家｜合作通關

第七週 H5 遊戲，共 **20 關**。第 1～10 關保留，第 11～20 關以現有機制組成更長的合作路線；第 19 關保留認可的「一起登上雲端」，第 20 關登頂後還有兩座移動冰橋。選單直接列出 1～20 關，沒有分類與額外試玩入口。一般版隱藏攻略、機關編號、路段標示與解答；只有 `?tip=true` 開啟教學版，並自動展開每關解答。

[開始遊戲](http://127.0.0.1:18128/) · [老師教學版](http://127.0.0.1:18128/?tip=true) · [第 11 關](http://127.0.0.1:18128/?level=11) · [第 20 關](http://127.0.0.1:18128/?level=20)

全部 20 關都完成後，貓咪和狗狗會一起走上舞台，聚光燈與彩紙慶祝，顯示 **「你們是最佳拍檔！」**。不必依順序通關，補完最後一個未完成的關卡也會觸發。支援減少動態偏好，關閉後可繼續選關；重整不重複彈出。

## 一起登上雲端

這是一張連續地圖，寬 3,300 單位，出口比起點高 1,000 單位。前段向右，後段向上，鏡頭追蹤兩個角色並依距離調整視野；角色在視野外時有貓狗方向標示。

| 路段 | 合作規則 |
| --- | --- |
| 日月移動冰橋 | 指定角色持續壓板才有橋，跳躍還會切換日月。輪流過橋與接手壓板，冰上用反方向提前減速。 |
| 重量蹺蹺板 | 兩人分站兩側，讓低處朋友跳起改變重量，慢慢升高。拿到貓咪鑰匙後兩板固定，再接回另一人。 |
| 雙層電梯交接 | 一人先搭、另一人送上樓；離開下層機關，等電梯降回來，再由上層角色接人。下一層交換工作。 |
| 日月登頂 | 連續月亮、太陽踏板向右上延伸。安排誰先爬，每次落地再由朋友幫跳，避免切掉另一人腳下的路。 |

整關只用移動與跳躍：**W 幫狗狗跳、↑ 幫貓咪跳**，方向控制自己，每次真的起跳都切換日月。沒有新增特殊鍵。兩把鑰匙分別放在蹺蹺板後與雲端屋頂，貓狗各拿一把。任何角色掉進深谷即整關失敗，沒有中途存檔點，可立即重試。

選第 19 關直接進入；教學版下方提供八步解答。第 20 關寬 4,200 單位，增加屋頂最後接力，解答共有十步。教學版上方狀態會隨位置顯示目前路段。

## 操作與既有規則

| 動作 | 貓咪 | 狗狗 |
| --- | --- | --- |
| 左右移動、冰面反向減速 | A／D | ←／→ |
| 跳躍；交換跳躍關卡改為幫朋友跳 | W | ↑ |
| 只在重力關：翻轉朋友重力 | S | ↓ |

畫面按鈕支援觸控。特殊動作長按只觸發一次，重來、切關與失焦會清除輸入。煞車、大小交換、停時間、滾球、泡泡玩法已移除，沒有 E／Enter 的額外遊玩動作。Enter 僅在失敗畫面用來重試。

冰面放手仍會滑，接近岸邊或壓板時要提前反向減速。七個既有冰關和大型難關的冰區都有慣性；大型關走出冰區後恢復一般地面操作。鑰匙碰到就能拿，不需停穩或落地；上方圖示、角色頭頂及操作卡都標示持有者。

角色臉表示由誰踩；機關編號僅在教學版顯示，用來對照解答。同號任一壓板持續被指定角色壓住，橋與門才開。一般重量門可以用箱子壓，角色專屬壓板不接受箱子。重箱要兩人貼近、同側同向推，不能隔空合推。

共 12 關有掉落失敗；重力關向上飄出也算失敗。另一人先到家不能豁免。按「重試本關」、Enter 或 R 還原整關，失敗不寫完成紀錄。沒有倒數或生命次數限制。

## 存檔與建置

紀錄沿用 `together-home-curated-v4`，依 `saveKey` 對應。第 1～10、19 關識別碼不變；重製的 11～18 關使用 `campaign-11-2` 至 `campaign-18-2`，第 20 關使用 `campaign-rooftop-1`。舊短版完成紀錄不會誤算新版通關。首次讀取仍可對應 `together-home-platform-v3`，不覆寫原始存檔。

`?level=1` 到 `?level=20` 依編號選關；加 `&tip=true` 同時啟用教學，例如 `?level=20&tip=true`。教學設定只依網址，不寫進存檔。舊網址 `?preview=ascent|swap|phase|gravity|bridge|ice|balance` 仍可對應保留的關卡，移除玩法的舊連結回第一關；畫面不再提供試玩分類。

`npm start` 開啟本機遊戲；`npm run build` 輸出 `dist/h5`，可雙擊 `index.html` 離線玩。新版離線包是 `dist/together-home-20-partners.zip`。課堂建置會包含完整遊戲檔案與全破舞台。

- `levels.js`：20 關地圖、解答與存檔識別碼。
- `core.js`、`physics.js`、`collision.js`：物理、大小地圖邊界、雙人鏡頭、掉落與碰撞。
- `mechanics.js`：重力、近距離幫跳、冰區與重量踏板。
- `app.js`：操作、選關、路段提示、重試、存檔與全破判定。
- `art.js`：貓狗、場景、捲動畫面、機關、鑰匙標示與舞台入場動畫。

`npm test` 使用正常輸入完成全部 20 關，驗證碰撞、掉幀、貼近合推、取鑰匙、冰區、壓板交接、電梯、重力、重量踏板及大地圖鏡頭。所有測試使用隔離進度，不更動使用者存檔。

設定 `PLAYWRIGHT_PATH` 後可執行：

- `node tests/ascent-browser.cjs`：真實鍵盤完成大型關，分段檢查向右／向上鏡頭，驗證失敗、重試、存檔、移除入口與手機排版；可用 `TOGETHER_URL` 指向離線檔案。
- `node tests/tutorial-browser.cjs`：檢查全部 20 關的一般／教學版、實際 Canvas 編號與提示、網址開關、操作通關及手機排版。
- `node tests/browser.cjs`：從空白進度以瀏覽器鍵盤事件完成全部 20 關，不注入角色位置、鑰匙或通關狀態。另驗證解答、鑰匙標示、進度遷移、觸控與全破舞台。記錄存於 `test-output/twenty-playthrough.json`，每關有起點與通關截圖。
- `node tests/finale-browser.cjs`：最後補完第一關的全破判定、重複／過期存檔、舞台動畫、減少動態、鍵盤焦點與關閉。
- `node tests/actions.cjs`：保留操作、移除玩法、特殊鍵、失敗與 320／375px 排版。
- `node tests/cooperation-browser.cjs`：建置後直接開離線檔，以鍵盤完成蹺蹺板、終極接橋與大型難關；`TOGETHER_LEVELS` 可指定關卡編號。
