# 貓狗一起回家｜20 關合作冒險

整合原本 20 關與兩個已確認的新玩法，汰換最簡單或重複的關卡，再重排成 **20 關**。第 7 關加入「連動箱子」，第 9 關加入「渡船接力」；第 16～20 關是大型組合挑戰。正式選單不加入未選用的「影子接班」。

[開始遊戲](http://127.0.0.1:18128/) · [老師教學版／自動解題](http://127.0.0.1:18128/?tip=true) · [最後五關](http://127.0.0.1:18128/?level=16)

## 開場、暖身與結局

一般入口先按「開始」，看貓咪和狗狗在路上碰面，用角色頭上的泡泡框聊三句後一起出發。約 14 秒後自動進入第 0 關，也可按「略過動畫」或 Escape 直接暖身；切換視窗時會暫停對話。

第 0 關是平地上的簡單合作：狗狗踩藍色圓圈開門，貓咪跳起拿鑰匙，兩人一起進屋。完成後按「開始第 1 關」進入原本的 20 關。暖身不計入正式通關紀錄；原有關卡、難度與存檔不變。直接連結 `?level=0` 可重玩暖身，`?level=0&tip=true` 有自動解題。指定關卡與老師版會直接進入遊戲。

正式 20 關全部完成後，貓狗結伴走回家，接著顯示「團結就是力量！」與「我們在一起的時候是最棒的！」。已全破的玩家可按「看結局」重看；支援減少動態偏好。

## 操作與畫面

貓咪用 A／D 移動、W 跳躍；狗狗用 ←／→ 移動、↑ 跳躍。交換跳躍關卡會直接在操作卡標示「幫朋友跳」；重力關才使用 S／↓ 翻轉朋友。渡船與連動箱子都只用原來的移動與跳躍，不新增技能鍵。

每關目標都是拿齊鑰匙，兩人一起到小屋。沒有倒數或生命限制。新機關關卡顯示一句短提示，其餘提示、編號與完整攻略在老師版顯示。掉河裡的角色或必要貨物會顯示重試，重來會還原箱子、船、升降台與鑰匙。

每組按鈕與對應的門、橋或升降台共用固定顏色及形狀；踩下時標記亮起，形狀不變。角色臉表示指定角色，箱子圖示表示必須放箱子。渡船各有標記，中島同時控制兩艘船的箭頭台會並列兩個標記。星星開關旁的日月圖示對應日月門與平台。

難度以熟悉單一機關、安排交班、重複利用物件、最後跨區規劃逐步提升。自動解題已知答案的操作時間不能代表學生解題難度。

最後五關地圖寬度依序為 2,440、3,120、3,300、4,200、4,840 單位：

- **雙城連動塔**：箱子不只取鑰匙，還要依序停在升降台、第一道門、最後一道門的方形座。最後須狗狗在樓上配合壓板。
- **渡船送貨上高塔**：先把兩個箱子送到中島與右岸，拿門後鑰匙固定開門，再取回同一個右岸貨箱，轉乘兩部升降台。頂樓同時需要貨箱與月亮。
- **一起登上雲端**：保留原本完整的冰橋、蹺蹺板、升降台和日月高空階梯。
- **雲端最後一棒**：保留雲端登塔後的屋頂移動冰橋交接。
- **連動貨運總站**：先解連動房間，兩人會合後接續雙船貨運，最後把右岸貨箱送上兩層樓。六把鑰匙、兩人到家才完成；全程是同一張地圖，沒有傳送或重置物件。

## 汰換與存檔

移除舊第 1、11、13、16、17 關：踩我一下、冰岸換班上樓、三段日月交換班、重量換跳登塔、冰谷重力第三棒。相關代表玩法仍由較完整的關卡保留。

保留的 15 張地圖只換順序，原本規則、解答、存檔識別碼不變。主線仍使用 together-home-curated-v4，依 saveKey 對應而非關卡號碼；原本全破紀錄會對應到保留的 15 關，5 張新地圖需要另行完成。舊關卡資料留作物理回歸測試，不出現在選單。

## 每關自動解題

網址加 ?tip=true 即可開啟老師版，20 關全部有「播放解題」，支援暫停、繼續、停止、重播及亮起操作按鍵。指定關卡例如 ?level=20&tip=true。示範不計入通關、不覆寫玩家進度，也不觸發回家結局；停止後可直接自行操作。

solutions.js 記錄每秒 120 個正常按鍵狀態，經 input.js 的按下／放開處理與相同物理引擎播放。沒有設定角色位置、代拿鑰匙、略過門或直接設定勝利。此次已按新 20 關順序重新錄製。

## 本地執行與課程建置

- npm start：在 18128 埠開啟開場、第 0 關與正式 20 關。
- npm run build：產生 dist/h5，可用瀏覽器開啟 index.html 離線遊玩。
- npm test：驗證現行 20 關通關、合作條件、存檔識別碼、慢幀碰撞與歷史機關回歸。
- npm run record:solutions：從正常按鍵解法重新產生示範；npm run check:solutions 驗證一致。
- 設定 PLAYWRIGHT_PATH 後，node tests/solutions-browser.cjs 會驗證 20 關播放與逐步輸入；npm run test:campaign:browser 會用真實鍵盤操作新增五關，並檢查舊進度對應、全破與手機排版。
- 設定 PLAYWRIGHT_PATH 後，node tests/browser.cjs 會透過瀏覽器鍵盤輸入逐關通過正式 20 關，檢查鑰匙、兩人到家、存檔、全破結局與手機操作。
- 課程端先 npm run build:classroom，再設定 CLASSROOM_ROOT=dist/classroom-h5 執行 node tests/classroom-seventh.mjs，驗證目錄連結、開場泡泡、暖身鍵盤通關、進入第 1 關及老師版示範。
- npm run test:story:browser：驗證開場對話、暫停／略過、暖身鍵盤通關、存檔隔離、結局重播及手機排版。
- npm run test:visual:browser：從正常按鍵產生 20 關各 4 個快照，檢查一般／老師版機關畫面與標籤，不修改遊戲進度。

第七週課程沿用既有遊戲與老師版入口。課程複製腳本與獨立建置均包含 warmup.js、story.js、campaign.js、puzzle-levels.js、puzzle-rules.js，讓離線版本也保有完整故事與機關。

## 本地原型保留

npm run start:lab 開啟 18129 埠的 [原三關試玩](http://127.0.0.1:18129/lab.html)，使用獨立存檔。渡船與連動箱子共用正式玩法原始碼；影子接班只留在此試玩入口。npm run test:lab、npm run check:lab 可驗證原型。

玩法構想參考 [《雙人成行》官方介紹](https://www.ea.com/games/it-takes-two/it-takes-two/features) 的雙人互補方向及 [《PICO PARK 2》官方介紹](https://picoparkgame.com/en/pp2/) 的多樣合作挑戰；地圖與素材為本專案原創組合。
