# 找寶石與青蛙換位

第六週候選玩法的兩款本地 H5 原型，共用入口、各有三個難度。純 HTML/CSS/JavaScript、自製 SVG 圖像，無外部執行依賴。不影響其他試玩遊戲，未加入正式課程或發布。

## 本地使用

```powershell
npm start
npm test
npm run build
```

- 找寶石：`http://127.0.0.1:18123/?game=scale`
- 青蛙換位：`http://127.0.0.1:18123/?game=frogs`
- 靜態檔輸出到 `dist/h5/`。

## 找寶石

3、6、9 顆同樣外觀的寶石，恰好一顆比較重。每次新開關卡隨機決定較重寶石。點寶石再點天平／盒子，或直接拖曳。左右放一樣多顆才能秤重，顯示大於、小於、等於並保存紀錄。移動寶石後清除當下讀數，歷史紀錄保留。

按「找到了」再點寶石回答，猜錯保留盤面與紀錄，不直接公布答案。沒有秤重次數限制；成功後才回顧用了幾次。可用分組排除在 1／2／2 次內解三關，但不強制最短解。右鍵或 Escape 取消選取。成功後可再玩該難度或下一關。

題型參考：[Math Is Fun — Weighing 9 Balls](https://www.mathsisfun.com/puzzles/weighing-9-balls.html)。

## 青蛙換位

每邊 2、3、4 隻青蛙，中間一格空荷葉。皇冠隊向右、花朵隊向左，不能後退。每次可以往前移一格，或跳過一隻對方青蛙到空格。滑鼠移上青蛙會標出可到的位置。全部交換位置即完成；無法繼續時提示退一步，可撤回、重來。

三關最短解為 8、15、24 步，不在遊玩畫面顯示步數壓力。窄螢幕的較大棋盤使用橫向捲動，維持青蛙與點選區大小。皇冠／花朵及方向箭頭同時區分隊伍，不只靠顏色。

題型參考：[NRICH — Frogs](https://nrich.maths.org/problems/frogs?tab=help)，採只能往前、跳過異隊一隻的版本。

## 進度與課堂考量

使用獨立 `localStorage` 鍵 `logic-garden-v1`。保存兩款遊戲當前盤面、天平紀錄、青蛙撤回歷史及完成標記。切遊戲保留盤面；點難度重新開該關但保留完成標記。資料不合法時回到初始狀態。

天平紀錄讓同伴可負責比對線索；青蛙目標與盤面同時可見，方便另一人規劃下一跳。不強制輪流操作或新增雙人限制。

## 驗證

`npm test` 檢查所有可能的較重寶石位置、天平比較及非法操作、青蛙合法移動、每關最短可解性、撤回與存檔驗證。

`node tests/browser.cjs` 用獨立 Playwright 瀏覽器檢查六關通關、拖曳、點選、觸控、重整保存、錯誤答案、撤回與多尺寸版面。需自行提供 Playwright；可用 `PLAYWRIGHT_PATH` 指定既有套件、`CHROME_PATH` 指定 Chrome。截圖放在忽略提交的 `dist/browser-check/`，不更動使用者的瀏覽器進度。
