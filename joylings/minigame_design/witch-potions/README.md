# 月見藥水舖：女巫的藥水訂單

開發與文字規範請見 [小遊戲開發規格](../開發規格.md)。

第五堂課的單機 H5 倒水益智試玩版，十張訂單。第一關是不用互倒的教學關；第 5 關起進階，第 9、10 關為高難度挑戰。v0.5.1 對外發布十關版，並同步至第 5 週課程入口；包含精簡文字、集中操作按鈕與課堂大字介面。

## v0.5：十位客人與後三關進階

- 第一關為「戀愛藥水」，保留裝滿、入鍋的教學；第 1～7 關每色最多 4 次操作。
- 第 8～10 關每色最多 5 次操作（含入鍋及必要清空）；玫瑰露確實需要 5 次才能量好入鍋，已用有界搜尋排除 4 次以內的捷徑。
- 第 8 關用 4 個量杯，第 9～10 關用 5 個；後三關示範解法共 11、13、15 次，遊戲不顯示計數也不限制玩家嘗試。
- 十位客人使用不同角色圖像：狼人、骷髏、貓頭鷹、南瓜精、水手、史萊姆、狐狸、白兔、螢火蟲、老魔法師。
- 好夢、人魚、誠實、發光、年輕藥水有對應瓶上圖案與成功演出；可愛改為戀愛，第 6 關保留漂浮。
- 存檔依容量與配方比對，相同配方保留；第 8～10 關變更的草稿與完成紀錄會重置。

最後一關再進階：三色示範解法各 5 次，分別練習分給兩杯、分次加入大鍋、清空接收杯後再分一次；玫瑰露與月光水都已驗證 4 次以內無解。

## 圖像操作

- 原料瓶、杯中原料、目標配方與結果用玫瑰、月亮、幽靈 SVG 圖示；目標配方另有藥水瓶與愛心、月亮、魚尾、誠實對話框、光芒、嫩芽等魔法圖案。
- 選取原料瓶或量杯後，容器跟隨滑鼠；倒入時播放約半秒的移動、傾斜與液流動畫。減少動態模式直接更新結果。

## 開始玩

直接雙擊 `START.cmd` 或 `index.html`，不需安裝套件、登入或連線。使用本機預覽伺服器時，執行 `npm start`，開啟終端機顯示的網址（預設 `http://127.0.0.1:4318/`，被占用時嘗試後續十個埠）。本機位址只供這台電腦使用。

遊戲執行檔是 `index.html`、`styles.css`、`game.js`、`app.js`，全部為本地資源。Windows 啟動器只開啟 HTML，不會安裝或啟動背景服務。圖案為原創 SVG，無外部字型或圖片依賴。

## 操作與規則

- 點原料，再點量杯：補到滿。點有藥液的量杯，再點另一杯、大鍋或垃圾桶：倒出。
- 每次倒到來源空或接收杯滿，不能指定份量、中途停倒。量杯只標容量，沒有刻度或剩餘量數字。
- 原料不限量。量杯內不混料，倒空後可換原料；不同原料只在大鍋中混合。
- 加入大鍋和垃圾桶時整杯倒空。大鍋不按目標配方截斷倒入量，也不能倒回量杯。累計 100 份為防誤操作上限，超過時拒絕整個動作，不會用上限量測。
- 配方需逐種原料完全相符，不能只對總量。客人試喝後顯示各原料偏多、偏少或剛好；失敗會清空本張訂單，交貨前仍可撤回或重來。
- 女巫小提示與從空杯開始的完整解法直接列在工作臺下方。所有關卡可直接選擇，每關分開保留草稿；瀏覽器儲存不可用時仍可正常玩。
- 完成紀錄與草稿存在當前瀏覽器，本機檔案與 HTTP 預覽可能使用不同的儲存空間。
- 移除「怎麼玩」教學視窗；用「重新開始」清空本張訂單，用「完成」確認配方。

## 驗證

`npm test` 使用 Node 內建測試執行器，驗證十關解法、前七關每色最多四次、後三關每色最多五次、五杯互動與客人不重複、容量與守恆、來源先空、目標先滿、補滿、拒絕混料、錯誤配方與撤回重播。

`npm run test:browser` 使用 Playwright 連至 `POTIONS_URL`（預設 `http://127.0.0.1:18118/`），以實際點擊驗證圖示、游標、右鍵取消、倒入動畫、鍋內配方、失敗清空與隔離其他草稿、十關通關、動畫切關、觸控、減少動態及 320／390／945／1365px 排版。可用 `POTIONS_PLAYWRIGHT_MODULE` 指定已安裝的 Playwright 模組、`CHROME_PATH` 指定 Chrome。報告與截圖位於忽略提交的 `dist/browser-check/`；遊玩不需要 Playwright。
