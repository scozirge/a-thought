# 月見藥水舖：女巫的藥水訂單

第五堂課的單機 H5 倒水益智試玩版，四張訂單：戀愛藥水、除草毒藥、青蛙變身藥水、黑貓變身藥水。

[第五堂課程入口](https://scozirge.github.io/classroom/#fifth-course) · [公開單機遊戲](https://scozirge.github.io/a-thought/witch-potions/)

## 開始玩

直接雙擊 `START.cmd` 或 `index.html`，不需安裝套件、登入或連線。使用本機預覽伺服器時，執行 `npm start`，開啟終端機顯示的網址（預設 `http://127.0.0.1:4318/`，被占用時嘗試後續十個埠）。本機位址只供這台電腦使用。

遊戲執行檔是 `index.html`、`styles.css`、`game.js`、`app.js`，全部為本地資源。Windows 啟動器只開啟 HTML，不會安裝或啟動背景服務。圖案為原創 SVG，無外部字型或圖片依賴。

## 操作與規則

- 點原料，再點量杯：補到滿。點有藥液的量杯，再點另一杯、大鍋或廢液桶：倒出。
- 每次倒到來源空或接收杯滿，不能指定份量、中途停倒。量杯只標容量，沒有刻度或剩餘量數字。
- 原料不限量。量杯內不混料，倒空後可換原料；不同原料只在大鍋中混合。
- 加入大鍋和廢液桶時整杯倒空。大鍋不按目標配方截斷倒入量，也不能倒回量杯。累計 100 份為防誤操作上限，超過時拒絕整個動作，不會用上限量測。
- 配方需逐種原料完全相符，不能只對總量。客人試喝後顯示各原料偏多、偏少或剛好；失敗保留所有操作，可撤回或重來。
- 提示與從空杯開始的完整解法收在提示視窗。所有關卡可直接選擇，每關分開保留草稿；瀏覽器儲存不可用時仍可正常玩。
- 完成紀錄與草稿存在當前瀏覽器，本機檔案與 HTTP 預覽可能使用不同的儲存空間。
- 「怎麼玩」底部可展開「重新開始四張訂單」，清除這個瀏覽器裡的草稿與完成紀錄。

## 題目

| 訂單 | 量杯容量 | 配方 | 內附解法操作數 |
| --- | --- | --- | --- |
| 戀愛藥水 | 5、3 | 2A＋3B | 5 |
| 除草毒藥 | 3、2 | 3B＋1C | 5 |
| 青蛙變身藥水 | 3、2 | 1A＋2B＋3C | 7 |
| 黑貓變身藥水 | 4、3 | 2A＋1B | 9 |

A 為玫瑰露、B 為月光水、C 為幽靈黏液，都是虛構原料。每次裝滿、轉倒、入鍋、倒掉各算一次操作；選取和交貨不計次。不設倒數或步數上限。

數學參考：[Measuring 4 Liters](https://www.mathsisfun.com/puzzles/measuring-4-liters.html)、[The Water Jugs](https://people.sc.fsu.edu/~jburkardt/fun/puzzles/jugs_puzzle.html)。本遊戲的角色、配方與單向入鍋規則為課堂改編。
