# 機器人補給站

第六週候選遊戲的本地 H5 原型，尚未加入正式課程目錄。三個任務：合併兩顆電池、依電量分流、將電量調成 8 格。

## 操作

- 將完整方塊拖進固定空格；全部放好後自動跑三台機器人。
- 第一關只放一個運算符號。第二、三關放一個條件和兩個動作，不需組合巢狀算式、輸入數字或接線。
- 也可直接點方塊，放入第一個相符的空格。要替換時，先點空格再點新方塊，或拖新方塊覆蓋。
- 「重來」清空這關的方塊；「再跑一次」重播。右鍵或 Esc 取消選取。
- 失敗保留方塊，換掉後自動重試；執行中修改或換關會中止舊動畫。
- 三關都可直接選擇。各關草稿與通關標記儲存在瀏覽器，無倒數、步數扣分或線上帳號。

## 啟動與驗證

```powershell
npm start
npm test
npm run build
```

本地網址為 http://127.0.0.1:18120/ 。純 HTML、CSS、JavaScript 與原創 SVG，不需安裝依賴。靜態輸出為 `dist/h5/`。

完整方塊會轉成白名單語法樹，沿用原本的運算與判斷規則，沒有執行使用者輸入的 JavaScript。空格未放滿不執行，不同種類不能放錯位置。新版使用獨立存檔 `robot-supply-simple-v2`，首次開啟繼承舊版通關標記，不覆寫舊版草稿。

兩人共用電腦可由一人拼方塊、一人先預測結果，過關交換；原型不強制交接或增加確認步驟。
