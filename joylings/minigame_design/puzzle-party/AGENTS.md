# 合作挑戰遊戲

- v0.16.2 連線急修：不得因 20 秒未收到應用層快照就自行離房；由 Fusion 的連線事件判斷斷線，ConnectionTimeout 為 60 秒。連線中可使用 Screen Wake Lock，離房釋放、回到前景重新要求；不保證背景分頁繼續運作。此次依使用者要求未追加瀏覽器實測，不能宣稱長時間跨網測試通過。
- v0.16.0：貼紙五頁、企鵝四頁 Unity 圖文教學，每頁只教一件事，大圖配短句。貼紙用紅底加小藍片的三格示範解釋覆蓋，A／B 另放一頁。入口在開始卡片與關卡工具列。連線由老師控制開啟／翻頁／關閉，房間快照同步教學遊戲與頁碼，晚加入跟隨；教學期間拒絕作答及播放，關閉保留作答、分工與關卡。播放中先停止才可開啟，離房清除。使用獨立 `puzzle-party-v16-simple-guide` 版本。`TutorialGuide.PageCount` 統一 UI 與房間頁數；`tests/tutorial-browser.cjs` 驗證實際 Photon 多端同步及 360／390／945／1365px。
- 最新 v0.16.1：只開放貼紙工廠與帶企鵝回家，各 20 關，共 40 關。動物拍照隊及傻瓜勇者已移出選單；歷史模組只供回歸驗證。
- 開放題庫由 `rules/catalog.js` 控制。貼紙 1～9、15 題與企鵝 1～4、11～20 題保留；新貼紙 10～14、16～20 題與企鵝 5～10 題由 `tools/generate-classroom.cjs` 固定產生至 `rules/classroom-levels.js`，使用 v13 ID。歷史題庫檔案只供回歸，不在遊玩時隨機出題。
- 面向國小二、三年級，前三關簡單。規則簡單、狀態公開、確定性結果；先設定再播放，播放後才呈現實際結果，重試保留設定。
- 每關固定四個有效作答位置，每個位置至少兩個選項。開題（open）時將在場學生隨機分配到前段；兩隊以上時，每位學生避免連續負責同一步，每位學生一步，剩下的後段全部為老師組，第四步永遠是老師。單機四步全部是老師組。不得再增加第五至八次作答或第二輪。未湊滿學生組時，由老師代答缺席組；單機老師可操作全部四組。
- 步驟以①②③④標示。連線每一步顯示實際負責者的自訂名稱，不附加你／老師／小隊字樣。長名稱換行；✓ 代表已選、… 代表未選，雙色需兩區都選好。主要字 18px、按鈕 20px，檢查 945／390／1365px。
- 貼紙不旋轉，後貼蓋前貼。10～14 題四層相鄰邊界依序 13～17，重貼 23～27 次，每層有效；15 題保留。16～20 題為雙色：前兩題兩色、規則形狀，後三題三色、彎折交錯，邊界 14／16／18。四張面積 16／12／8／4，每個 A、B 區連通且最後可見至少兩格，唯一解。結構指標不等同兒童實測難度。
- 企鵝碰冰或邊界才停，到家也繼續讀指令，四步後判定。前十題單隻，前三題較少方向；5～10 題唯一且最短四步、每步有效，4×4 過渡至 5×5。11～20 題保留雙隻、單邊多解且合起來唯一四步；19、20 題含先到家再離家。保留暫停與 2 倍速。
- 所有效果與暫停同步凍結。停止、失敗與重試保留四個設定；清空清除四組。不同關卡 ID 不混用保存資料。
- 不使用需要等待別人的稀缺道具、隱藏消耗或隨機路線。
- Unity 連線參考 RIVALS Photon Fusion Host／Client。`asia`、獨立 `AppVersion=puzzle-party-v16-simple-guide`；老師建房，學生從 Photon 清單選房；雙方組別名稱預設空白且必填。加入順序只決定內部席位身分，第 1～3 步依每次開題的抽籤結果分配；離房補入最前空組，不重編其他組，可同時作答且只能改本題分配的 slot，不能以組號當步驟。作答階段晚加入者立即接手前三步中由老師持有的空步驟，其他學生與既有答案不變；播放或結果階段加入者等待下次開題；離房原步驟交老師，其他人不移位；清空／停止不重新分工。老師負責後段並可代答學生；只有老師能切關、清空、播放、暫停、繼續、停止及調速。學生不能用 UI 或指令橋繞過權限。
- 老師與單機可用「？」查看當題答案，學生不可使用；答案只在本機呈現，不加入房間快照。連線視窗一直提供「返回單機」，包含尚未連線、連線中、失敗與已連線；取消須完成清理後關閉視窗。
- 學生離房保留答案，老師可接手，空組可重新加入。老師離房即關房，不把教師身分自動轉給學生。播放狀態以教師權威計時同步；單機草稿與房間狀態分開。
- v0.10.1 連線清理期間維持忙碌並以 epoch 排除舊流程；延遲拒絕必須確認仍在 rejected。使用 Fusion 自訂 RealtimeClient 將老師房間 PlayerTtl 設為 0，避免刷新後 Photon 的 15 秒 inactive 席位占住四人上限；停用 SDK 自動換房。重連仍以明確重新加入／建房為準，不能擴大學生組數。
- Unity 本地 HTTP 8191 也可連真實 Photon，跨網不用同一區網。公開版為 https://scozirge.github.io/a-thought/puzzle-party/ ，公開頁與同版本本地 Unity 分享包可加入同一房間。`127.0.0.1` 不是遠端分享地址。只維護 Unity WebGL，支援單機與跨網連線。
- 僅維護 Unity 6.3 `unity-game/`；`rules/` 是題庫匯出與 Editor 對照驗證工具，不是可玩的 H5 版本。Unity C# 規則、IMGUI 操作及動畫獨立執行，不能用網頁包裝冒充 Unity。
- 專案源自 RIVALS 的獨立複製；`unity-base/` 保留來源 Assets、Packages、ProjectSettings、Tools。不得改動原 RIVALS、混入其連線房間或發布到原 RIVALS 網址。
- `npm test` 的 59 項測試驗證 40 題唯一解、固定四個有效選擇、每層可見、形狀連通、企鵝雙邊必要性／最短步數／沒有共同空等，並保留歷史回歸。`npm run analyze` 產生結構分析，不可把組合數或唯一解當成兒童實測難度。
- `npm run build:unity` 使用 Unity 6000.3.11f1。`tools/export-unity.cjs` 匯出 40 關，JS 與 C# 各完整列舉 26,905 組設定，逐關比對成敗及最終畫面資料的 SHA-256、案例數與成功數。摘要只放 Editor。`Editor/PuzzleRoomChecks.cs` 另驗證 9,234 個案例，包含開題分工、房間權限、雙色部分作答與全部老師答案。
- Unity WebGL 輸出 `Builds/UnityWeb`，本機 HTTP 8190；被占用時啟動器改用 8191。`tests/unity-browser.cjs` 驗證真正 WebGL、40 關、滑鼠／觸控、四次作答與暫停。跨瀏覽器多人房間必須另實測，不能以 Editor 檢查取代或提前宣稱通過。
- `tools/package-unity.cjs` 補齊本地啟動工具與說明；Unity 分享包須包含 `ThirdPartyLicenses/`、Noto 字體授權、SDK 內 Photon 聲明／NanoSockets 授權等原文。保留啟動工具行為，勿散布無法載入的 file:// WebGL。
