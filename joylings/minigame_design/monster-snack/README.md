# 怪獸點心屋｜邏輯小廚師

第六堂課的第一版單機 H5。學生拼接工作表，指揮小幫手調整點心份量、製作口味並送給怪獸。適合兩人共用電腦：一人看訂單、預測結果，一人安排方塊；過關後交換角色，不限制單人操作。

## 開啟遊戲

在本資料夾執行 `npm start`，或雙擊 `START.cmd`。預設網址是 `http://127.0.0.1:4320/`；若被占用，會依序嘗試到 4330，請依終端顯示的網址開啟。

執行 `npm run build:h5` 後，產生：

- `dist/monster-snack.html`：可直接雙擊的單檔離線版。
- `dist/h5/`：可放到一般靜態網站的五個檔案，全部使用相對路徑，無 CDN 或外部素材依賴。

使用 HTTP 版本可獲得較一致的瀏覽器進度保存行為；直接開啟本機 HTML 的保存行為依瀏覽器而異。此版本先提供本機試玩，尚未加入正式課程目錄或發布至網站。

## 怎麼玩

1. 看左側客人的需求：`x` 是盤子裡的點心數量，`y` 是客人想吃的數量。
2. 點方塊加入工作表，也可拖曳新增。要放進 if 或 case，先點該分支的空格，再點方塊。
3. 用方塊右上方的拖曳把手搬動，也可用上／下箭頭調整同一分支內的順序。叉號刪除方塊，復原可撤回編輯或清空。
4. 按「開始」自動播放，或按「一步」觀察一個指令。播放中可暫停；按「重來」回到第一筆訂單，保留工作表並重新開放編輯。
5. 同一份工作表必須通過本關的每筆訂單，才會記錄完成。點下方訂單可先看不同客人的初始數值；執行固定從第一筆開始。

方塊逐關增加；選關選單可直接查看任一關，方便老師示範、分級與學生回練。進度與每關工作表存在當前瀏覽器的 `monster-snack-v1`，沒有帳號或連線需求。無法使用儲存功能時會提示。

## 規則與第一版範圍

- `y` 是唯讀的訂單數量；算術方塊修改 `x`，運算值可選 x、y 或 0～12。
- `=` 表示比較相等；「把 x 設為」表示更新數量。乘號使用 `×`，除號使用 `÷`。
- if 每次只判斷一次；if / else 只走一個分支，沒有隱藏的重複執行。
- switch 依怪獸種類執行一個 case；暖暖龍、雪棉兔、布丁怪各有分支，蘑菇仔走 default。每個 case 自動結束，不穿透到下一個分支。
- 送餐會檢查份量與指定口味；成功就結束當前訂單。後方指令不再執行。
- 第四關未符合條件的訂單必須原樣留在廚房，不得修改數量、口味或送出。
- 點心數量限 0～24 的整數，禁止負數、除零及無法整除。錯誤保留原數值並定位出錯方塊。
- 工作表最多 36 個方塊、分支最多巢狀四層；沒有倒數或步數競賽。
- 這版的重點是數量、條件與分類；未加入地圖走格子、多人同步、迴圈、AND／OR、可新增 case 條件或一般文字程式編輯器。
- 角色與插圖為本專案製作的 SVG，未使用《7 Billion Humans》的美術、關卡或程式碼。

## 驗證

`npm test` 驗證全部關卡的參考解法、分支語意、錯誤邊界與資料驗證；`npm run build:h5` 也會檢查所有解法和本機資源。

`npm run test:browser` 使用 Playwright 與 Chrome，對隔離的瀏覽器資料執行測試，不修改玩家存檔。需先執行 `npm run build:h5` 並啟動本機伺服器；可透過 `SNACK_PLAYWRIGHT_MODULE` 指定 Playwright 模組路徑、`CHROME_PATH` 指定 Chrome、`SNACK_URL` 指定網址。涵蓋拖曳、分支編輯、全部關卡播放、暫停與重來、進度保存、320～1440px 響應式畫面、觸控分支編輯與離線單檔通關。截圖輸出至忽略追蹤的 `dist/browser-check/`。
