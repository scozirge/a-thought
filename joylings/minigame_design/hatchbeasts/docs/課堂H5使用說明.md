# 遊戲設計｜本地課堂 H5

公開課堂目錄：[https://scozirge.github.io/a-thought/hatchbeasts/classroom/](https://scozirge.github.io/a-thought/hatchbeasts/classroom/)。目錄使用不帶版號的固定網址；教材中的「玩目前遊戲 v1」仍連到遊戲的固定版本。

課堂首頁是六個單元的目錄。「遊戲體驗與發想」的標題可進入教材，右側的「展開活動」按鈕可顯示五個子項目；子項目會直接連到教材對應的位置。

第一單元包含兩題原始選項、九種蛋與怪獸配對、五個發想問題與設計草圖提示。目錄的「玩破殼怪獸 v1」和教材頁的「玩目前遊戲 v1」都會另開同一個公開固定版本，方便回到教材。

公開遊戲：[破殼怪獸 v1](https://scozirge.github.io/a-thought/hatchbeasts/v1/)。此入口需要網路；要離線試玩，可直接開啟下方的本機遊戲網址。

其餘五個單元目前是保留入口的封面頁，顯示「本單元內容準備中」。

## 開發預覽

在專案資料夾執行 `npm run dev`，開啟終端機 Local 網址下的 `/classroom/`。例如：`http://localhost:3000/classroom/`。

## 本地 H5 輸出

建議使用 Node 22：

```sh
npx --yes --package=node@22 node scripts/build-classroom.mjs
```

已使用 Node 22 時也可以執行 `npm run build:classroom`。輸出位於 `dist/classroom-h5/`，包含教材、原版遊戲、全部圖片、字型與程式。

在專案資料夾執行：

```sh
python -m http.server 4317 --bind 127.0.0.1 --directory dist/classroom-h5
```

- 課堂目錄：[http://localhost:4317/classroom/](http://localhost:4317/classroom/)
- 第一單元：[http://localhost:4317/classroom/experience/](http://localhost:4317/classroom/experience/)
- 本機遊戲：[http://localhost:4317/](http://localhost:4317/)

本地版本使用 HTTP 伺服器提供檔案，不直接雙擊 HTML。可將整個 `classroom-h5` 資料夾複製到其他已安裝 Python 的電腦，再依其中的 `START.txt` 啟動；不依賴線上圖片、網路字型或 API。

## 編輯教材

- `app/classroom/page.tsx`：目錄與展開／收合。
- `app/classroom/experience/page.tsx`：第一單元內容。
- `app/classroom/course-data.ts`：目錄、子項目、蛋與怪獸資料、發想問題。
- `app/classroom/classroom.css`：課堂專用的紙張、蠟筆色塊、響應式排版。
- `app/classroom/course-ui.tsx`：共用導覽與待補單元的封面。

插圖沿用遊戲已有的蠟筆小怪獸素材；標題字型使用同一個 Iansui 來源的課堂專用子集，授權附在 `public/fonts/OFL-Iansui.txt`。

此版本只在本機製作與預覽。
