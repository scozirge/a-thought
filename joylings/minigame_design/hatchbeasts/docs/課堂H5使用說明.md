# 遊戲設計｜課堂 H5

公開課堂目錄：[遊戲設計課](https://scozirge.github.io/a-thought/hatchbeasts/classroom/)。目錄使用不帶版號的固定網址。

課堂首頁包含「第一次課程｜破殼怪獸」、「第二次課程｜紅藍槍戰」及其餘五個待補單元。點課程標題可進入教材；右側按鈕可展開活動或題目，直接連到教材對應的位置。

第二次課程：[紅藍槍戰](https://scozirge.github.io/a-thought/hatchbeasts/classroom/red-blue-battle/)。四個題目分別是「目前遊戲中有哪些武器？」、「這些武器有什麼特點？」、「還可以加什麼武器？」及「角色可以有什麼技能？」。答案範例預設收起，點題目或「看答案範例」即可展開，也支援鍵盤操作。

課堂目錄及第二次課程的「玩紅藍槍戰」會另開 [最新版公開遊戲](https://scozirge.github.io/a-thought/rivals/?v=touch-fix-20260924)。大廳可選手機觸控或鍵盤滑鼠，兩種模式都能全螢幕；建立房間或加入朋友的房間，最多 8 位真人，空位由電腦角色補齊。隊伍先達 30 擊殺獲勝，死亡 3 秒後隨機復活。新增武器與技能的範例是課堂發想，並非已實作功能。

第一單元包含兩題原始選項、九種蛋與怪獸配對、五個發想問題與設計草圖提示。目錄的「玩破殼怪獸 v1」和教材頁的「玩目前遊戲 v1」都會另開目前的公開遊戲，方便回到教材。

公開遊戲：[破殼怪獸](https://scozirge.github.io/a-thought/hatchbeasts/)。此入口需要網路；要離線試玩，可直接開啟下方的本機遊戲網址。

其餘五個單元目前是保留入口的封面頁，顯示「本單元內容準備中」。

## 開發預覽

在專案資料夾執行 `npm run dev`，開啟終端機 Local 網址下的 `/classroom/`。例如：`http://localhost:3000/classroom/`。

## 本地 H5 輸出

建議使用 Node 22：

```sh
npx --yes --package=node@22 node scripts/build-classroom.mjs
```

已使用 Node 22 時也可以執行 `npm run build:classroom`。輸出位於 `dist/classroom-h5/`，包含教材、原版遊戲、全部圖片、字型與程式。

在專案資料夾執行：

```sh
python -m http.server 4317 --bind 127.0.0.1 --directory dist/classroom-h5
```

- 課堂目錄：[http://localhost:4317/classroom/](http://localhost:4317/classroom/)
- 第一單元：[http://localhost:4317/classroom/experience/](http://localhost:4317/classroom/experience/)
- 第二次課程：[http://localhost:4317/classroom/red-blue-battle/](http://localhost:4317/classroom/red-blue-battle/)
- 本機遊戲：[http://localhost:4317/](http://localhost:4317/)

本地版本使用 HTTP 伺服器提供檔案，不直接雙擊 HTML。可將整個 `classroom-h5` 資料夾複製到其他已安裝 Python 的電腦，再依其中的 `START.txt` 啟動；教材本身不依賴線上圖片、網路字型或 API，紅藍槍戰連結則需要網路。

## 編輯教材

- `app/classroom/page.tsx`：目錄與展開／收合。
- `app/classroom/experience/page.tsx`：第一單元內容。
- `app/classroom/red-blue-battle/page.tsx`：第二次課程與答案範例展開／收起。
- `app/classroom/course-data.ts`：目錄、子項目、蛋與怪獸資料、發想問題。
- `app/classroom/classroom.css`：課堂專用的紙張、蠟筆色塊、響應式排版。
- `app/classroom/course-ui.tsx`：共用導覽與待補單元的封面。

插圖沿用遊戲已有的蠟筆小怪獸素材；標題字型使用同一個 Iansui 來源的課堂專用子集，授權附在 `public/fonts/OFL-Iansui.txt`。

公開版本使用 GitHub Pages，教材建置與發布方式見專案 README。紅藍槍戰的 Web 成品另外發布於 `gh-pages` 分支的 `rivals/`，包含 `Build` 與素材授權文件。

## 紅藍槍戰操作

在大廳選「手機觸控」或「鍵盤滑鼠」，兩種模式都可用右上角「全螢幕」；不支援原生全螢幕的瀏覽器會改為填滿可用視窗。

手機左側搖桿移動、右側滑動轉向，按住射擊可連射並轉向。瞄準點一下開啟、再點一下關閉，顯示「瞄準中」時放開手指仍會保持，可繼續射擊。失焦返回後直接觸碰操作區即可繼續，不再顯示中央操作提示。另有跳躍、衝刺、裝填與選單。

鍵鼠點遊戲畫面後以 WASD 移動、滑鼠轉向、左鍵開火、按住右鍵瞄準、放開取消，R 換彈、Esc 選單。若瀏覽器不支援滑鼠鎖定，會自動顯示相容操作：按住右鍵拖曳轉向，放開移回後可再拖曳。需要連續自由轉向時，請在獨立 Chrome 或 Edge 開啟正式遊戲網址，再點畫面開始。

所有版本已移除滑行；同房前請所有人重新載入網頁，Windows 玩家也需下載新版，以確保使用相同連線版本。
